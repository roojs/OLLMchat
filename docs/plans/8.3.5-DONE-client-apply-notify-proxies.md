## Purpose

- **🔷** `✔️` When `live_handles` is on, `Client` applies inbound `notify::` onto a **local** proxy the app already bound (handle id → `GLib.Object`).
- **🔷** `✔️` Apps still construct and destroy proxies (`Window.created` / `Window.closed`).
- **🔷** `✔️` Unbound ids skip apply and still emit `notification`.
- **🔷** `✔️` Smoke: dummy `GLib.Object` with `string title`; bind; inject `notify::title`; property updates with no app `switch`.
- **💩** `✔️` Bind API is public `Client.proxies` (`Gee.HashMap<int, GLib.Object>`). App uses `proxies.set` / `proxies.unset`.
- **💩** `✔️` After apply, still emit `notification` (proxy also gets GObject `notify`).
- **💩** `✔️` `disconnect()` clears `proxies`.
- **💩** `⏳` This plan is **string `Notification.message` only** (matches Subscribe today: `title`, `wm_class`). Bool / int / nested `Rectangle` wait for a later plan once Subscribe stops string-only `get_property`.
- **ℹ️** Subscribe (`8.3.2`) is unchanged. Wire stays `method` + `id` + `message`.
- **ℹ️** gnome-shell-rpc (other tree): after this lands, drop the `notify::title` branch; `list_windows` / close still `proxies.set` / `unset`; keep `Window.created` / `Window.closed`.

Intro: edits are **Remove** / **Replace with** / **Add** from the tree;
verify surrounding context before applying.

### 1. `libocrpc/Client.vala` — `proxies` map

**Why:** Per-client registry of handle → local proxy. Same Gee `int` key as server leases. Empty when unused.

**Where:** class body, immediately after `live_handles`.

**Depends on:** none.

#### Add — after `public bool live_handles { get; set; default = false; }` — app-owned proxy table

```vala
		/**
		 * Handle id → local proxy when {@link live_handles} is on.
		 *
		 * The app inserts after it constructs the proxy
		 * ({@link Gee.HashMap.set}) and removes on closed
		 * ({@link Gee.HashMap.unset}). Inbound ''notify::'' notifications
		 * call {@link GLib.Object.set_property} from
		 * {@link Notification.message}. Unbound ids still emit
		 * {@link notification}.
		 *
		 * == Example ==
		 *
		 * {{{
		 * rpc.proxies.set(notif.id, win);
		 * rpc.proxies.unset(notif.id);
		 * }}}
		 */
		public Gee.HashMap<int, GLib.Object> proxies {
			get;
			set;
			default = new Gee.HashMap<int, GLib.Object>();
		}
```

### 2. `libocrpc/Client.vala` — `dispatch_message`: apply `notify::`

**Why:** Every live client was copying the same strip-prefix + assign. Apply here when the id is bound.

**Where:** `dispatch_message`, `Notification` branch, after `buffer_stream.attach`, before `this.notification(notif)`.

**Depends on:** §1.

##### Part 1 — `set_property` from `message` when bound

**Keep**

```vala
				if (this.buffer_stream != null) {
					this.buffer_stream.attach(notif);
				}
```

#### Add — immediately after the `buffer_stream.attach` block, before `this.notification(notif)` — string apply for bound `notify::`

```vala
				if (this.live_handles
					&& notif.method.has_prefix("notify::")
					&& this.proxies.has_key(notif.id)) {
					var current = GLib.Value(typeof(string));
					current.set_string(notif.message);
					this.proxies.get(notif.id).set_property(
						notif.method.substring(8),
						current
					);
				}
```

**Keep**

```vala
				this.notification(notif);
				return;
```

### 5. `tests/rpc/proxies-test.vala` — smoke

**Why:** Dummy GObject with `string title`. Real `Client` read loop (apply lives in `dispatch_message`). Unix listen + hello so `connect` succeeds, then `broadcast` a `Notification`.

**Where:** new file.

**Depends on:** §1–§3.

#### Add — create `tests/rpc/proxies-test.vala`

```vala
/*
 * Copyright (C) 2026 Alan Knowles <alan@roojs.com>
 *
 * Client proxy apply smoke — types here are NOT shipped in libocrpc.
 */

namespace OLLMrpcTests
{
	public class Probe : GLib.Object
	{
		public string title { get; set; default = ""; }
	}

	public class Hello : GLib.Object
	{
		public signal void call_hello(OLLMrpc.Request request);

		construct
		{
			this.call_hello.connect((request) => {
				request.reply(new OLLMrpc.Response());
			});
		}
	}

	class TestRpcProxies : RpcTestAppBase
	{
		public TestRpcProxies()
		{
			base("com.roojs.ollmchat.test-rpc-proxies");
		}

		protected override string get_app_name()
		{
			return "test-rpc-proxies";
		}

		protected override void run_rpc_test(ApplicationCommandLine command_line) throws Error
		{
			OLLMrpc.Bin.register("CallParam", typeof(OLLMrpc.CallParam));
			OLLMrpc.Request.register(
				"RPC-Daemon",
				new Hello(),
				typeof(OLLMrpc.CallParam)
			);
			var dir = GLib.DirUtils.make_tmp("ocrpc-proxies-XXXXXX");
			var sock = GLib.Path.build_filename(dir, "rpc.sock");
			var listen = new OLLMrpc.Transport.SocketListen(sock) {
				live_handles = true
			};
			this.check(command_line, listen.start(), "listen start failed");
			var rpc = new OLLMrpc.Client("", "", sock) {
				live_handles = true
			};
			var probe = new Probe();
			rpc.proxies.set(7, probe);
			var connected = false;
			var loop = new GLib.MainLoop();
			rpc.connect.begin(new OLLMrpc.Request() {
				method = "RPC-Daemon.hello"
			}, null, (obj, res) => {
				connected = rpc.connect.end(res);
				loop.quit();
			});
			loop.run();
			this.check(command_line, connected, "client connect failed");
			var seen = "";
			rpc.notification.connect((notif) => {
				seen = notif.message;
			});
			var apply_loop = new GLib.MainLoop();
			probe.notify["title"].connect(() => {
				apply_loop.quit();
			});
			var timeout_id = GLib.Timeout.add(2000, () => {
				apply_loop.quit();
				return false;
			});
			listen.broadcast(new OLLMrpc.Notification() {
				method = "notify::title",
				id = 7,
				message = "a"
			});
			if (probe.title != "a") {
				apply_loop.run();
			}
			GLib.Source.remove(timeout_id);
			this.check(command_line, probe.title == "a", "proxy title not applied");
			this.check(command_line, seen == "a", "notification signal not emitted");
			rpc.proxies.unset(7);
			var unbound_loop = new GLib.MainLoop();
			var unbound_timeout = GLib.Timeout.add(2000, () => {
				unbound_loop.quit();
				return false;
			});
			listen.broadcast(new OLLMrpc.Notification() {
				method = "notify::title",
				id = 7,
				message = "b"
			});
			if (seen != "b") {
				unbound_loop.run();
			}
			GLib.Source.remove(unbound_timeout);
			this.check(command_line, seen == "b", "unbound notification not emitted");
			this.check(command_line, probe.title == "a", "unbound id still applied");
			rpc.disconnect();
			this.check(command_line, rpc.proxies.size == 0, "disconnect left proxies");
			listen.stop();
		}
	}
}

int main(string[] args)
{
	return new OLLMrpcTests.TestRpcProxies().run(args);
}
```

## LLM notes

- Domain types stay out of `libocrpc`. Tests use dummy `GLib.Object`s.
- Do not add `Client.bind` / `Client.unbind` / apply helpers. Inline in `dispatch_message`. App uses `proxies.set` / `unset`.
- Do not auto-construct proxies from `Notification.object_type`.
- Do not revive `Notification.payload` (`8.3.3`).
- Do not change Subscribe or `Notification` wire in this plan.
- Do not apply named signals (`closed`, `Window.created`). Prefix `notify::` only.
- Do not turn `live_handles` on for ollmfilesd.
- Build: `ninja -C build tests/test-rpc-proxies && build/tests/test-rpc-proxies` (keep `test-rpc-subscribe` green).
