# 8.4.6 — Remaining typelib convert tags

> `docs/plans/1.0-summary.md` is **not** updated for this sub-plan until it is done and archived.

**Status:** **PROPOSED** — spare. No fences until a topic is designed.

**Parent:** [`8.4-rpc-positional-values-and-ffi.md`](8.4-rpc-positional-values-and-ffi.md)

## Purpose

What 8.4.2 / 8.4.3 dumped as “extra `convert` tags” that [`8.4.5`](8.4.5-rpc-ffi-leftovers.md) did not take. After 8.4.5, `convert` / `scalar` still `INVALID_PARAMS` for these.

- **🔷** `⏳` `FLOAT` / `DOUBLE` — GIR tags. `StreamValue` has no float cases today.
- **🔷** `⏳` `ARRAY` — GIR tag. `StreamValue` carries `string[]` only.
- **🔷** `⏳` `GValue.transform` into the GIR width (wire `INT` → tag `INT64`) — inside `convert`, not a second helper.
- **🔷** `⏳` `ENUM` / `FLAGS` as `TypeTag.INTERFACE` — not blobs, not leases. 8.4.5 leaves `n == 0` → `INVALID_PARAMS`. gnome-shell-rpc [`0.5.2`](file:///home/alan/git/gnome-shell-rpc/docs/plans/0.5.2-close-gi-stub-gaps.md) Phase 1 already emits them on the client.
- **🔷** `⏳` Reconstruct `Gio.File` from URI/path both ends. `Gi.register` only walks `InfoType.OBJECT`, so File is never leased.
- **💩** `⏳` INOUT boxed — [`8.4.5`](8.4.5-rpc-ffi-leftovers.md) first walk is caller-allocates OUT only.
- **ℹ️** Boxed GObject `INTERFACE`, `GLib.Bytes` wire, caller-allocates OUT: [`8.4.5`](8.4.5-rpc-ffi-leftovers.md).
- **ℹ️** Huge blobs / SCM_RIGHTS: extend [`8.3.4`](8.3.4-DONE-scm-rights-fds.md), not this parent.

---

## Float / double

- **🔷** `⏳` `StreamValue` write / read for `GLib.Type.FLOAT` / `DOUBLE`.
- **🔷** `⏳` `convert` / `scalar` `TypeTag.FLOAT` / `DOUBLE` once the wire can carry them.

No fences until the wire layout is confirmed (fundamental type byte already exists; payload width is not in 8.4.5).

---

## Array

- **🔷** `⏳` `convert` / `scalar` `TypeTag.ARRAY` (C arrays in GIR: length, zero-terminated, `argv`, …).
- **🔷** `⏳` `StreamValue` must carry the element GType, not only `string[]`.
- **💩** `⏳` `TypeTag.GLIST` / `GSLIST` / `GHASH` — gnome-shell-rpc 0.5.2 Phase 4 (`list_all_windows`). Not the same tag as `ARRAY`.
- **ℹ️** gnome-shell-rpc 0.5.2 Phase 5 is blocked on C arrays in libocrpc.

No fences until element types and length pairing are confirmed.

---

## Width

- **🔷** `⏳` Wire integer width can disagree with the GIR tag (`INT` vs `INT64`). `GValue.transform` in `convert` before filling `GI.Argument`.
- **ℹ️** 8.4.5 does not fence this. Scalar tags that already match still work.

---

## ENUM / FLAGS

- **🔷** `⏳` `TypeTag.INTERFACE` + `InfoType.ENUM` / `FLAGS` → integer in `GI.Argument` (`v_int` / `v_uint` from the enum storage). Same `convert_interface` `n == 0` path today.
- **ℹ️** Not a `GLib.Bytes` blob. Not a lease.

---

## INOUT boxed

- **💩** `⏳` 8.4.5 first arg walk is caller-allocates **OUT** only. INOUT boxed (caller buffer that is also an IN blob) is not in that fence.

---

## GInterface / `Gio.File`

- **🔷** `⏳` Both ends reconstruct from a URI or path string — not a lease.
- **🔷** `⏳` `Gi.register` walking `InfoType.INTERFACE` (so a File GType can appear on the wire) — or skip register and only reconstruct.
- **ℹ️** Unregistered GObject GTypes stay `INVALID_PARAMS` (8.4.5).
