# 2.9.2 — Disable HTTP `web_fetch` / `google_search` / `web_search`

> **Do not update `docs/plans/1.0-summary.md` for this plan** until archived (Focus already points here).

**Status:** **ACTIVE** — simple retire of the old HTTP tools now that **`browser`** (5.0) is the real path.

**Pointer:** `docs/guide-to-writing-plans.md` — Checklist for plans

---

## Purpose

- **🔷** Stop exposing **`web_fetch`**, **`google_search`**, and the **`web_search`** wrap to agents / the tool list.
- **🔷** Prefer **`browser`** (`fetch` / `search` / …) from [`5.0-webkit-control.md`](5.0-webkit-control.md).
- **🔷** Keep source in-tree for now (unregister / disable only) — delete later if unused.
- **🔷** Point internal callers that still hardcode `web_fetch` at **`browser`** (or another remaining path).

---

## Why now

- **ℹ️** 5.0 said coexistence until browser proved out; core browser tool is shipped.
- **ℹ️** HTTP fetch/search duplicate the browser actions with a worse (non-session) path.

---

## Scope

### Unregister / disable

- **⏳** `liboctools/Registry.vala` — stop `register_tool` / `setup_tool_config_default` for `WebFetch.Tool` and `GoogleSearch.Tool` (and stop `typeof(…).ensure()` if nothing else needs them).
- **⏳** Wrapped tools: `resources/wrapped-tools/WebFetch.tool`, `resources/wrapped-tools/WebSearch.tool` — stop loading / remove wrap registration.
- **⏳** Android registration (`ollmapp/android/…`) — same disable if still registering these.
- **⏳** Skills / prompts that list `web_fetch` / `web_search`:
  - `resources/skills/research_web_page.md`
  - `resources/skills/research_online_search.md`
  - `resources/skill-prompts/task_refinement.md` (URL guidance)
  - `resources/tools/huggingface-help.md` (discovery wording → `browser`)
- **⏳** Config defaults / Tools page — no longer advertise these as first-class enabled tools (stale `Config2.tools` entries can remain harmless).

### Call sites that still assume `web_fetch`

- **⏳** `liboccoder/Task/ResolveLink.vala` — `load_http` uses `tools.get("web_fetch")`; switch to **`browser`** `action: fetch` (markdown) or an agreed replacement so task HTTP refs keep working.
- **⏳** Grep for remaining `"web_fetch"` / `"google_search"` / `"web_search"` in Vala + skills after unregister.

### Out of scope

- **🚫** Deleting `liboctools/WebFetch/` / `GoogleSearch/` trees in this pass.
- **🚫** Reworking 1.15 truncate / 2.9.1 HTML→MD cleanup plans (obsolete once tools are off).

---

## Success

- **⏳** Fresh session tool list has **`browser`**, not `web_fetch` / `google_search` / `web_search`.
- **⏳** Research skills instruct **`browser`** (or are retired).
- **⏳** Task HTTP reference resolution still works without registering `web_fetch`.
