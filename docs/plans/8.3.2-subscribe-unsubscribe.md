## Purpose

- **🔷** `⏳` Client asks for `notify::title` (and named signals) on a handle. Server does not flood every property on every window.
- **🔷** `⏳` Same `live_handles` flag as [`8.3.1`](8.3.1-live-handles-and-remote-refcount.md).
- **🔷** `⏳` `SubscribeSignal` / unsubscribe (names from gnome-shell-rpc `0.1`). Args: handle, signal or property name.
- **🔷** `⏳` Server connects that GObject signal **for that connection only**. Unsubscribe and connection drop disconnect.
- **🔷** `⏳` Inbound `notify` → `Notification` with handle, property name, current value.
- **🔷** `⏳` Named signals (`closed`, …) → `Notification` with handle and signal name.
- **🔷** `⏳` Tests: subscribe, change a prop, see one notification; unsubscribe, change again, silence.
- **ℹ️** Flag off: these methods are not used. ollmfilesd keeps broadcast `Notification`s.

## Subscribe RPC

- **💩** `⏳` Wire `Subscribe.signal` / `Subscribe.unsubscribe` (`Object.method`).
  - gnome-shell-rpc `SubscribeSignal` maps to `Subscribe.signal`.
  - Unsubscribe maps to `Subscribe.unsubscribe`.
  - Same mapping as `RemoteRef` → `Remote.ref`.
- **💩** `⏳` New `SubscribeParams` + `Subscribe` in `libocrpc/Subscribe.vala`.
  - `Request.register` is one param type per handler class.
  - Subscribe needs `name`. Do not add it to `RemoteParams` (would appear on `Remote.ref` / `Remote.unref`).
- **💩** `⏳` `Connection.subs`: `Gee.HashMap<int, Gee.HashMap<string, ulong>>`.
  - Outer key is lease id (`int`, same Gee `uint64` key hole as leases).
  - Inner map is subscribed name → GObject handler id.
- **💩** `⏳` `Notification` fields until [`8.3.3`](8.3.3-notification-gobject-payload.md):
  - `method` = subscribed name (`notify::title` or `closed`)
  - `id` = `(int)` handle
  - `message` = string property value for `notify::` (empty if `get_string` is null)
  - Named signals leave `message` empty
  - No new `uint64` handle field and no GObject payload in this plan
- **🔷** `⏳` Disconnect on `Subscribe.unsubscribe`, on `Remote.unref` of the export hold, and at the start of `Connection.stop()`. Extra client refs do not unsubscribe.

### 1. `libocrpc/Subscribe.vala` — new handler + params

**Why:** Process-wide `call_*` handler, same shape as `libocrpc/Remote.vala`. Table is still per `request.connection`.

**Where:** new file. Meson lists are §6–§8.

**Depends on:** §2 (`subs` on `Connection`).

#### Add — create `libocrpc/Subscribe.vala` (`SubscribeParams` + `Subscribe` with `call_signal` / `call_unsubscribe` inline in `construct`)

```vala
/*

 * Inc., 51 Franklin Street, Fifth Floor, Boston, MA  02110-1301  USA
 */

namespace OLLMrpc
{
	/**
	 * Params for {@link Subscribe} signal / unsubscribe.
	 *
	 * == Example ==
	 *
	 * {{{
	 * var req = new OLLMrpc.Request() {
	 *     method = "Subscribe.signal",
	 *     param = new OLLMrpc.SubscribeParams() {
	 *         object_id = handle,
	 *         name = "notify::title"
	 *     }
	 * };
	 * }}}
	 */
	public class SubscribeParams : CallParam
	{
		public uint64 object_id { get; set; default = 0; }
		public string name { get; set; default = ""; }

		public static void rpc_register()
		{
			Bin.register("SubscribeParams", typeof(SubscribeParams));
		}
	}

	/**
	 * Process-wide handler for live-handle signal subscribe.
	 *
	 * Uses {@link Request.connection} so each peer has its own sub table.
	 * Wire type is {@link SubscribeParams} only. Handler wiring is
	 * {@link Request.register} at server boot, not a method on this class.
	 *
	 * == Example ==
	 *
	 * {{{
	 * OLLMrpc.SubscribeParams.rpc_register();
	 * OLLMrpc.Request.register(
	 *     "Subscribe", new OLLMrpc.Subscribe(), typeof(OLLMrpc.SubscribeParams));
	 * var req = new OLLMrpc.Request() {
	 *     method = "Subscribe.signal",
	 *     param = new OLLMrpc.SubscribeParams() {
	 *         object_id = handle,
	 *         name = "notify::title"
	 *     },
	 *     connection = connection
	 * };
	 * req.dispatch();
	 * }}}
	 */
	public class Subscribe : GLib.Object
	{
		public signal void call_signal(Request request);
		public signal void call_unsubscribe(Request request);

		construct
		{
			this.call_signal.connect((request) => {
				if (!request.connection.live_handles) {
					request.connection.reply_error(request, (int) RpcErrorCode.METHOD_NOT_FOUND);
					return;
				}
				var param = request.param as SubscribeParams;
				if (param == null) {
					request.connection.reply_error(request, (int) RpcErrorCode.INVALID_PARAMS);
					return;
				}
				var id = (int) param.object_id;
				if (!request.connection.leases.has_key(id)) {
					request.connection.reply_error(request, (int) RpcErrorCode.INVALID_PARAMS);
					return;
				}
				if (param.name.length == 0) {
					request.connection.reply_error(request, (int) RpcErrorCode.INVALID_PARAMS);
					return;
				}
				if (!request.connection.subs.has_key(id)) {
					request.connection.subs.set(id, new Gee.HashMap<string, ulong>());
				}
				if (request.connection.subs.get(id).has_key(param.name)) {
					request.reply(new Response());
					return;
				}
				var obj = request.connection.leases.get(id);
				if (param.name.has_prefix("notify::")) {
					request.connection.subs.get(id).set(param.name, obj.notify[param.name.substring(8)].connect((pspec) => {
						var current = GLib.Value(typeof(string));
						obj.get_property(pspec.name, ref current);
						var text = current.get_string();
						text = text != null ? text : "";
						request.connection.write(new Notification() {
							method = param.name,
							id = id,
							message = text
						});
					}));
					request.reply(new Response());
					return;
				}
				request.connection.subs.get(id).set(param.name, GLib.Signal.connect(obj, param.name, (GLib.Callback) () => {
					request.connection.write(new Notification() {
						method = param.name,
						id = id
					});
				}, null));
				request.reply(new Response());
			});
			this.call_unsubscribe.connect((request) => {
				if (!request.connection.live_handles) {
					request.connection.reply_error(request, (int) RpcErrorCode.METHOD_NOT_FOUND);
					return;
				}
				var param = request.param as SubscribeParams;
				if (param == null) {
					request.connection.reply_error(request, (int) RpcErrorCode.INVALID_PARAMS);
					return;
				}
				var id = (int) param.object_id;
				if (!request.connection.leases.has_key(id)) {
					request.connection.reply_error(request, (int) RpcErrorCode.INVALID_PARAMS);
					return;
				}
				if (!request.connection.subs.has_key(id) || !request.connection.subs.get(id).has_key(param.name)) {
					request.connection.reply_error(request, (int) RpcErrorCode.INVALID_PARAMS);
					return;
				}
				GLib.SignalHandler.disconnect(request.connection.leases.get(id), request.connection.subs.get(id).get(param.name));
				request.connection.subs.get(id).unset(param.name);
				request.reply(new Response());
			});
		}
	}
}
```

**Why:** Subscriptions are per connection, not process-wide.

### 3. `libocrpc/Transport/Connection.vala` — `stop()`: disconnect then drop

**Why:** Connection drop must disconnect before extras / `leases.clear()`, while the table still holds the objects.

**Where:** `stop()` body — first lines, before the extras `foreach`.

**Depends on:** §2.

##### Part 1 — disconnect all subs before extras unref

#### Add — immediately after `public virtual void stop()` `{` — disconnect every stored handler, then `subs.clear()`

```vala
			foreach (var id in this.subs.keys) {
				foreach (var name in this.subs.get(id).keys) {
					GLib.SignalHandler.disconnect(this.leases.get(id), this.subs.get(id).get(name));
				}
			}
			this.subs.clear();
```

### 4. `libocrpc/Remote.vala` — `call_unref`: drop subs with the export hold

**Where:** `call_unref` lambda, after `var obj = request.connection.leases.get(id);`, before `lease_ids.unset`.

**Depends on:** §2.

### 9. `tests/rpc/subscribe-test.vala` — smoke

**Why:** Dummy GObject with a string `title` and a `closed` signal. Capture `write()` because in-process `Connection` has no channel (`write` no-ops otherwise).

**Where:** new file.

**Depends on:** §1–§4.

#### Add — create `tests/rpc/subscribe-test.vala`

```vala
/*
 * Copyright (C) 2026 Alan Knowles <alan@roojs.com>
 *
 * Subscribe smoke — types here are NOT shipped in libocrpc.
 */

namespace OLLMrpcTests
{
	public class Probe : GLib.Object
	{
		public string title { get; set; default = ""; }
		public signal void closed();
	}

	public class Capture : OLLMrpc.Transport.Connection
	{
		public OLLMrpc.Notification last { get; set; default = new OLLMrpc.Notification(); }
		public int writes { get; set; default = 0; }

		public override void write(GLib.Object gobject)
		{
			if (!(gobject is OLLMrpc.Notification)) {
				return;
			}
			this.last = (OLLMrpc.Notification) gobject;
			this.writes++;
		}
	}

	public static int main(string[] args)
	{
		var conn = new Capture() {
			live_handles = true
		};
		OLLMrpc.RemoteParams.rpc_register();
		OLLMrpc.SubscribeParams.rpc_register();
		OLLMrpc.Request.register("Remote", new OLLMrpc.Remote(), typeof(OLLMrpc.RemoteParams));
		OLLMrpc.Request.register("Subscribe", new OLLMrpc.Subscribe(), typeof(OLLMrpc.SubscribeParams));
		var probe = new Probe();
		var id = conn.export(probe);
		var sub = new OLLMrpc.Request() {
			method = "Subscribe.signal",
			param = new OLLMrpc.SubscribeParams() {
				object_id = id,
				name = "notify::title"
			},
			connection = conn
		};
		if (!sub.dispatch()) {
			GLib.printerr("Subscribe.signal notify dispatch failed\n");
			return 1;
		}
		probe.title = "a";
		if (conn.writes != 1) {
			GLib.printerr("notify did not write one Notification\n");
			return 1;
		}
		if (conn.last.method != "notify::title") {
			GLib.printerr("notify method mismatch\n");
			return 1;
		}
		if (conn.last.id != (int) id) {
			GLib.printerr("notify id mismatch\n");
			return 1;
		}
		if (conn.last.message != "a") {
			GLib.printerr("notify value mismatch\n");
			return 1;
		}
		var unsub = new OLLMrpc.Request() {
			method = "Subscribe.unsubscribe",
			param = new OLLMrpc.SubscribeParams() {
				object_id = id,
				name = "notify::title"
			},
			connection = conn
		};
		if (!unsub.dispatch()) {
			GLib.printerr("Subscribe.unsubscribe dispatch failed\n");
			return 1;
		}
		probe.title = "b";
		if (conn.writes != 1) {
			GLib.printerr("unsubscribe did not silence notify\n");
			return 1;
		}
		var closed_sub = new OLLMrpc.Request() {
			method = "Subscribe.signal",
			param = new OLLMrpc.SubscribeParams() {
				object_id = id,
				name = "closed"
			},
			connection = conn
		};
		if (!closed_sub.dispatch()) {
			GLib.printerr("Subscribe.signal closed dispatch failed\n");
			return 1;
		}
		probe.closed();
		if (conn.writes != 2) {
			GLib.printerr("closed did not write one Notification\n");
			return 1;
		}
		if (conn.last.method != "closed") {
			GLib.printerr("closed method mismatch\n");
			return 1;
		}
		if (!sub.dispatch()) {
			GLib.printerr("Subscribe.signal notify re-sub dispatch failed\n");
			return 1;
		}
		conn.stop();
		probe.title = "c";
		if (conn.writes != 2) {
			GLib.printerr("stop did not silence notify\n");
			return 1;
		}

		var held = new Capture() {
			live_handles = true
		};
		var held_probe = new Probe();
		var held_id = held.export(held_probe);
		var held_sub = new OLLMrpc.Request() {
			method = "Subscribe.signal",
			param = new OLLMrpc.SubscribeParams() {
				object_id = held_id,
				name = "notify::title"
			},
			connection = held
		};
		if (!held_sub.dispatch()) {
			GLib.printerr("unref-path Subscribe.signal dispatch failed\n");
			return 1;
		}
		var drop = new OLLMrpc.Request() {
			method = "Remote.unref",
			param = new OLLMrpc.RemoteParams() {
				object_id = held_id
			},
			connection = held
		};
		if (!drop.dispatch()) {
			GLib.printerr("Remote.unref export-hold dispatch failed\n");
			return 1;
		}
		held_probe.title = "d";
		if (held.writes != 0) {
			GLib.printerr("Remote.unref did not silence notify\n");
			return 1;
		}

		var off = new OLLMrpc.Transport.Connection();
		var off_req = new OLLMrpc.Request() {
			method = "Subscribe.signal",
			param = new OLLMrpc.SubscribeParams() {
				object_id = 1,
				name = "notify::title"
			},
			connection = off
		};
		if (!off_req.dispatch()) {
			GLib.printerr("flag-off Subscribe.signal dispatch failed\n");
			return 1;
		}
		if (off.subs.size != 0) {
			GLib.printerr("flag off still stored a sub\n");
			return 1;
		}
		return 0;
	}
}
```

## LLM notes

- Domain types stay out of `libocrpc`. Tests use dummy `GLib.Object`s.
- Do not stall the compositor waiting for the client. `connection.write` of a `Notification` is fire-and-forget.
- GObject payload on `Notification` is [`8.3.3`](8.3.3-notification-gobject-payload.md), not this plan.
- Handler wiring is `Request.register("Subscribe", new Subscribe(), typeof(SubscribeParams))` at server boot (tests / mutter plugin), same split as `Remote`.
- Do not turn the flag on for ollmfilesd or existing `Client` call sites.
- Do not snapshot `subs.keys` in `stop()` / `Remote.unref`. Those loops do not mutate the map they iterate. `clear` / `unset` is after the loop.
- `var obj = request.connection.leases.get(id)` in `call_signal` is the 4-step chain (`request.connection.leases.get`). Needed so the notify lambda can `get_property` on the same instance.
- Do not put `get_string()` on both sides of a ternary, and do not put a ternary in the `Notification` object initializer (Vala codegen / use-after-free). Call once into a local, then `text = text != null ? text : ""`. See `examples/oc-vala-ternary-bug.vala`.
- If `GLib.Signal.connect` rejects the named-signal lambda, stop and update this plan. Do not add a `handle_*` trampoline method.
- Named-signal tests use a void `closed()` with no extra args. Signals with extra parameters (e.g. `window-created`) wait for [`8.3.3`](8.3.3-notification-gobject-payload.md).
- Build: `ninja -C build tests/test-rpc-subscribe && build/tests/test-rpc-subscribe` (and keep `test-rpc-live-handles` green).
- **🚫** New helper to disconnect a handle’s subs. Inline the loop at each site.
- **🚫** `Request.register` inside `rpc_register`. `rpc_register` stays `Bin.register` only.
