# 8.5.3 — `Response.result` becomes a `GLib.Value`

> **Do not update `docs/plans/1.0-summary.md` for this plan.**

**Status:** **PROPOSED**

**Parent:** [`8.5-rpc-drop-callparam-reply-value.md`](8.5-rpc-drop-callparam-reply-value.md) — this is that file’s Phase 3. FFI handler walk is ✔️ there.

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**; proposed Vala follows **`docs/coding-standards.md`**

**Related:** [`docs/bin-rpc-protocol.md`](../bin-rpc-protocol.md) §15 / root `result` arrays. [`8.3.3-REJECTED-notification-gobject-payload.md`](8.3.3-REJECTED-notification-gobject-payload.md) — GObject `payload` on `Notification` stays withdrawn.

---

## Purpose

- **🔷** `⏳` Delete `Response.result` (`Gee.ArrayList<GLib.Object>`).
- **🔷** `⏳` Reply payload is one `GLib.Value`, written with `StreamValue` (object, object list, scalar, …).
- **🔷** `⏳` `Gi` stops `response.result.add(obj)`.
- **🔷** `⏳` `StreamValue` must write live-handle objects and read `OBJECT` in `read_array`.
- **ℹ️** `Response.args` (GI return + OUT) stays unless folded in review.
- **ℹ️** No fences until the property shape below is confirmed.

---

## Today

- **ℹ️** `Response.result` is a never-null object list. Empty is omitted on the wire. One row is still a one-element list.
- **ℹ️** Encode / decode is special-cased in `Response.bin_write_prop` / `bin_read_prop` (`libocrpc/Response.vala`).
- **ℹ️** Scalars already use `Response.args` (`ANY[]`, same as `Request.args`). `msg` / `msg_encode` is File.read.
- **ℹ️** HTTP client builds a `Response` and `result.add(obj)` (`libocrpc/Client.vala`).

---

## Shape (pick before fences)

- **💩** `⏳` Property: `GLib.Value result` on `Response`
  vs fold the payload into `Response.args` and drop `result`.
- **💩** `⏳` GI return and OUT: keep `args` slots vs one `ANY[]` value.
- **💩** `⏳` Fold `msg` / `msg_encode` into that value, or leave File.read as today.
- **💩** `⏳` Notification uses the same value shape. 8.3.3 GObject `payload` stays withdrawn.

No protocol version bump if the bytes stay `StreamValue` / object array. Confirm against `docs/bin-rpc-protocol.md` when the property name is picked.

---

## Consumers (after shape)

- **🔷** `⏳` `libocrpc/Response.vala` — property + `bin_write_prop` / `bin_read_prop`
- **🔷** `⏳` `libocrpc/Gi.vala` — stop `response.result.add`
- **🔷** `⏳` `libocrpc/Client.vala` — HTTP `result.add(obj)`
- **🔷** `⏳` `libocfiles` — `File`, `Folder`, `FileHistory`, `ProjectManager`, `ProjectFiles`, `ReviewFiles`
- **🔷** `⏳` `liboctools` — `ReadFile/Summarize`, `HuggingFace/Request`
- **🔷** `⏳` `libochf/Model.vala`
- **🔷** `⏳` `examples/oc-vector-search.vala`, `examples/oc-vector-index.vala`
- **🔷** `⏳` `tests/rpc/gi-test.vala` — `result.size` / `result.get(0)`
- **ℹ️** Callers today cast `(Gee.ArrayList<T>) response.result`. That cast has to change with the new property.
