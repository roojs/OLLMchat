# 8.5.3 — `Response.result` becomes a `GLib.Value`

> **Do not update `docs/plans/1.0-summary.md` for this plan.**

**Status:** **PROPOSED**

**Parent:** [`8.5-rpc-drop-callparam-reply-value.md`](8.5-rpc-drop-callparam-reply-value.md) — this is that file’s Phase 3. FFI handler walk is ✔️ there.

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**; proposed Vala follows **`docs/coding-standards.md`**

**Related:** [`docs/bin-rpc-protocol.md`](../bin-rpc-protocol.md) §15 / root `result`. [`8.3.3-REJECTED-notification-gobject-payload.md`](8.3.3-REJECTED-notification-gobject-payload.md) — GObject `payload` on `Notification` stays withdrawn.

Edits are **Remove** / **Replace with** / **Add** from the tree; verify surrounding context before applying.

---

## Purpose

- **🔷** `⏳` Delete `Response.result` as `Gee.ArrayList<GLib.Object>`. Property is one `GLib.Value`.
- **🔷** `⏳` Encode / decode that value with `StreamValue` (object, object list, scalar).
- **🔷** `⏳` `Gi` stops `response.result.add(obj)`.
- **🔷** `⏳` `StreamValue` writes live-handle objects and reads `OBJECT|0x80` via `parse_object_array`.
- **🔷** Keep `Response.args` for GI return + OUT. Leave `msg` / `msg_encode` (File.read).
- **ℹ️** No protocol version bump. Both ends change in one cut. Bytes stay `StreamValue` / object array.

---

## Shape

- **🔷** Property stays named `result` (`GLib.Value`). Do not fold the payload into `args`.
- **🔷** Unset (`GLib.Type.INVALID`) is omitted on the wire (same as empty list today).
- **🔷** One GObject → `set_object` on the value (bare `OBJECT`, not a one-element list).
- **🔷** N GObjects → `Gee.ArrayList` boxed in the value (`OBJECT|0x80`).
- **🔷** GI scalars stay on `args`. Object / object-list returns go on `result`.
- **💩** `⏳` Notification `GLib.Value` — not this cut. 8.3.3 GObject `payload` stays withdrawn.

---

## Today

- **ℹ️** `result` is a never-null object list. Empty is omitted. One row is still a one-element list.
- **ℹ️** Encode / decode is special-cased in `Response.bin_write_prop` / `bin_read_prop`.
- **ℹ️** `StreamValue.write` throws if the object is not `Serializable` (no live-handle path).
- **ℹ️** `StreamValue.read_array` has no `OBJECT` case. Object arrays only work through `Response`.

---

## Phase 1 — `StreamValue` live handle + object array

- **🔷** `⏳` Move the live-handle lease write out of `Response` into `StreamValue.write`.
- **🔷** `⏳` A `GLib.Value` whose GType is `typeof(Gee.ArrayList)` writes as today’s `result` object array (`0xD0` + gtype + count + bodies). Check `val.type().is_a(typeof(Gee.ArrayList))` — not `get_object() is Gee.ArrayList` (generic; `ArrayList<File>` is not `ArrayList<GLib.Object>`). Same GType as in-tree JSON: `Value(typeof(Gee.ArrayList)); set_object(list)`.
- **🔷** `⏳` `OBJECT|0x80` is handled in `read()` **before** `read_array`. `parse_object_array` reads gtype then count. Numeric `read_array` reads count then a slab — do not reuse that for objects.

### 1. `libocrpc/Bin/StreamValue.vala` — `write`: live handle + `ArrayList`

**Why:** `Response.result` will call `StreamValue.write`. Live handles and object lists must work there, or `Gi` / daemon replies break.

**Where:** `write()`, the `GLib.Type.OBJECT` branch at the end (after FLAGS).

**Depends on:** none.

#### Remove

```vala
			if (val.type().is_a(GLib.Type.OBJECT)) {
				if (val.get_object() == null) {
					return;
				}
				if ((val.get_object() as Serializable) == null) {
					throw new StreamError.PROTOCOL(
						"value type '%s' is not Bin.Serializable",
						val.get_object().get_type().name()
					);
				}
				ctx.write_gtype(val.get_object().get_type());
				((Serializable) val.get_object()).bin_write(ctx);
				return;
			}
```

#### Replace with

```vala
			if (val.type().is_a(GLib.Type.OBJECT)) {
				if (val.get_object() == null) {
					return;
				}
				if (val.type().is_a(typeof(Gee.ArrayList))) {
					var list = (Gee.ArrayList<GLib.Object>) val.get_object();
					ctx.write_gtype(list.get(0).get_type(),
						(uint8) GLib.Type.OBJECT | 0x80);
					if (list.size < 128) {
						ctx.out_stream.put_byte((uint8) list.size);
					} else {
						ctx.out_stream.put_byte(
							(uint8) (0x80 | ((list.size >> 8) & 0x7F)));
						ctx.out_stream.put_byte((uint8) (list.size & 0xFF));
					}
					foreach (var child in list) {
						if (!child.get_type().is_a(typeof(Serializable))
							&& ctx.connection.live_handles) {
							var ptr = (uint64) (void*) child;
							ctx.out_stream.put_uint64((uint64) ctx.connection.lease_ids.get(
								(int) (ptr >> 32)).get((int) ptr));
							ctx.out_stream.put_uint16(Stream.TOKEN_END);
							continue;
						}
						((Serializable) child).bin_write(ctx);
					}
					return;
				}
				if (!val.get_object().get_type().is_a(typeof(Serializable))
					&& ctx.connection.live_handles) {
					var live = val.get_object();
					ctx.write_gtype(live.get_type());
					var ptr = (uint64) (void*) live;
					ctx.out_stream.put_uint64((uint64) ctx.connection.lease_ids.get(
						(int) (ptr >> 32)).get((int) ptr));
					ctx.out_stream.put_uint16(Stream.TOKEN_END);
					return;
				}
				if ((val.get_object() as Serializable) == null) {
					throw new StreamError.PROTOCOL(
						"value type '%s' is not Bin.Serializable",
						val.get_object().get_type().name()
					);
				}
				ctx.write_gtype(val.get_object().get_type());
				((Serializable) val.get_object()).bin_write(ctx);
				return;
			}
```

### 29. `docs/bin-rpc-protocol.md` — §15 root `result`

**Why:** Spec still says `Gee.ArrayList<GLib.Object>` and forbids a bare object.

**Where:** `### Root result arrays (`Response.result`)` through “See `libocrpc/Response.vala`.” Also the override-recipes row for root list result.

**Depends on:** ### 3, ### 4.

#### Remove

```markdown
### Root result arrays (`Response.result`)

List **results** (`fetch_files`, …) encode as an object array on the **`result`** property of **`OLLMrpc.Response`** — not as a separate root message.

**Property type:** **`Gee.ArrayList<GLib.Object>`** — **`default = new Gee.ArrayList<GLib.Object>()`**; never null. Handlers populate **`result`** (length 0, 1, or N). Single-row RPCs use a one-element list — **🚫** no bare object on **`result`**.

**Encode:** omit **`result`** when **`result.size == 0`**. When **`size > 0`**, **`Response.bin_write_prop`** writes reg-id-first object arrays (`0xD0` + element `reg_id` + count + bodies); element **`GType`** from **`result.get(0)`**. **🚫** no **`is_array`** / **`result_type`** on handlers.

**Decode:** property present → **`Stream.parse_object_array()`**; property absent → default empty list. Clients: guard **`response.error`** only — **🚫** no **`response.result == null`**; one **`(Gee.ArrayList<T>) response.result`** cast — **🚫** no **`(Gee.ArrayList<GLib.Object>)`** hop. Single-row methods use **`list.get(0)`** when **`list.size > 0`**.

See `libocrpc/Response.vala`.
```

#### Replace with

```markdown
### Root result (`Response.result`)

Reply payload is one **`GLib.Value`** on **`OLLMrpc.Response.result`**, encoded with **`Bin.StreamValue`**. Not a separate root message.

**Omit** when the value is unset (`GLib.Type.INVALID`) or an empty **`Gee.ArrayList`**.

**One GObject:** type byte `OBJECT` (`0x50`) + body (property stream, or lease id + `TOKEN_END` when **`live_handles`**). **N GObjects:** object array (`0xD0` + element `reg_id` + count + bodies), same layout as before. **Scalar:** same type byte + payload as **`Request.args`** elements.

**Decode:** **`StreamValue.read`**. Object arrays use **`parse_object_array()`** (gtype then count — not the numeric-array slab). Property absent → unset value. Clients: guard **`response.error`**, then **`result.type()`**. One object → **`result.get_object()`**. A list → **`(Gee.ArrayList<T>) result.get_object()`**.

See `libocrpc/Response.vala`, `libocrpc/Bin/StreamValue.vala`.
```

```markdown
| Root list **result** | Override on **`Response.bin_write_prop`** / **`bin_read_prop`**; omit **`result-type`** / **`is-array`** on write; decode via **`parse_object_array()`** | `libocrpc/Response.vala` |
```
