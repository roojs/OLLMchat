# 8.5 — Drop `CallParam`; FFI handler dispatch; reply as `GLib.Value`

> **Do not update `docs/plans/1.0-summary.md` for this plan.**

**Status:** **PROPOSED** — Phase 1 (8.5.1) agent ✔️ consumer cut; Phase 2 (FFI dispatch) ⏳ fences below; Phase 3 (reply `GLib.Value`) ⏳.

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**; proposed Vala follows **`docs/coding-standards.md`**

**Builds on:** [`8.4-rpc-positional-values-and-ffi.md`](8.4-rpc-positional-values-and-ffi.md) — positional `GLib.Value` lists, `OLLMrpc.args` D-Bus signatures, and libffi via `Gi` already exist. 8.4 left `CallParam` and `call_*` signals in place on purpose.

**Related:** [`docs/bin-rpc-protocol.md`](../bin-rpc-protocol.md) §15 (`ANY[]`), root `Response.result` object arrays. [`8.3.3-REJECTED-notification-gobject-payload.md`](8.3.3-REJECTED-notification-gobject-payload.md) — GObject `payload` on `Notification` was withdrawn; a `GLib.Value` is a different question.

---

## Purpose

- **🔷** Phase 1: migrate **every** `CallParam` consumer (handlers + callers) to **`Request.args`** / `OLLMrpc.args(...)`. Delete the bags only when nothing reads `request.param`.
- **🔷** `OLLMrpc.args("s", path)` (D-Bus signature + Vala `...`) only boxes. Lease / `export` / live wire stays on Request write (`StreamValue`).
- **🔷** Phase 2: FFI dispatch instead of `call_*`, phased: (1) registration API (2) dispatch uses it when the method is listed (3) migrate methods one at a time, first **`RPC-Daemon.hello` only**. Unlisted methods keep `call_*`. Listed methods are **instance** methods. `this` is the default registered object leased on that connection (`export` + existing `lease_ids`). Caller omits `lease_id`. No static / prefix.
- **🔷** Phase 3: replace **`Response.result`** (`Gee.ArrayList<GLib.Object>`) with a reply **`GLib.Value`** (and maybe `Notification`). That is **not** the next step.
- **⏳** Sub-plans: **8.5.1** = migrate inventory below + delete bags; **8.5.2** fences are in this file (register → dispatch-if-listed → `hello` first); **8.5.3** = reply `GLib.Value`.
- **ℹ️** Infrastructure already in tree: `OLLMrpc.args`, `Request.args` / `Response.args` (rename from `values`). Phase 1 work left is leftover bag delete / docs. Phase 2 is the next code cut.

**Suggested order:** migrate CallParam consumers (8.5.1) → delete bags / `Request.param` → register API (8.5.2.1) → dispatch-if-listed (8.5.2.2) → `hello` only (8.5.2.3) → remaining methods later → reply `GLib.Value` (8.5.3). Can overlap remaining 8.4 FFI; 8.5.3 needs `StreamValue` live-handle / `OBJECT[]`.

## Phase 2 — FFI instance methods instead of `call_*` signals

- **🔷** `call_*` signals exist because dispatch could not call an arbitrary method. `Request.args` + D-Bus signatures now make that possible.
- **🔷** Roll out in three cuts. Do not convert every handler in one go. Do not start Phase 3 until the walk is done (or explicitly split).

### Contract (all three cuts)

- **🔷** Each handler class already has `rpc_register()`. That is where the method list lives. It calls the one central `Request.register`.
- **🔷** Central `Request.register`: wire class name, `GLib.Type`, then Vala `...` pairs of method name + D-Bus signature (same letters as `OLLMrpc.args`). One signature. We change it. We do not add a second `Request.register`.
- **🔷** Listed methods are **instance** methods. No static path. No prefix on the method name.
- **🔷** `this` comes from a lease. Default RPC objects are already instances (`this.daemon`, `this.project_manager`, …). Registration keeps that instance. The caller does **not** send `lease_id`.
- **🔷** Default instance → lease uses the existing maps: `Connection.export` writes `leases` (id → object) and `lease_ids` (object pointer → id). Dispatch then uses the standard lease path (`leases.get(id)`), same as `Gi.dispatch_function`.
- **🔷** `live_handles` is the **wire** flag (encode a live GObject, `RPC-Live-Remote.ref` / `unref`, subscribe). Reusing `export` / `leases` for default RPC `this` does not turn that flag on. Drop the `live_handles` guard on `export`.
- **🔷** If the request already has a `lease_id`, that lease wins (live object). If `lease_id == 0`, export/look up the registered default for that prefix, then the same path.
- **🔷** C ABI: object first, then `Request`, then the signature.
- **🔷** Empty extra args use `""` (method still receives `Request`).
- **🔷** Dots in the wire suffix become underscores in the C symbol (`changed.check` → `changed_check`).
- **🔷** C symbol is Vala's usual `namespace_class_method` (`OLLMfilesdDaemon` + `hello` → `ollmfilesd_daemon_hello`).
- **🔷** The registered signature does **not** start with `o` for `Request`.
- **🔷** No return value. Replies stay `request.reply(...)` / `reply_error`.
- **ℹ️** This path is libffi on **our** C symbols. Not GI / typelib / `Gi.vala`. `windows/Gi.vala` is unrelated.
- **ℹ️** `rpc_register()` already calls `Bin.register` for the wire type. That stays. The `Request.register` call is added there (today Application calls `Request.register(name, instance)` instead).

Intro: edits are **Remove** / **Replace with** / **Add** from the tree;
verify surrounding context before applying.

### 2.1 — Registration only

- **🔷** `⏳` Change central `Request.register` to `(name, type, ...)` and store the method table.
- **🔷** Every `call_*` stays. No handler bodies move yet. No dispatch change yet.

- **ℹ️** Per-class `rpc_register()` does not have to list methods in this cut.
- **ℹ️** Varargs are method/signature pairs, then `null` (GLib terminator).

```vala
		 * Register listed instance methods for a wire prefix.
		 *
		 * Pair method suffix with a D-Bus signature (same letters as
		 * {@link args}). End the list with ''null''. The live singleton
		 * still goes on {@link handlers} at boot (not this call).
		 *
		 * == Example ==
		 *
		 * {{{
		 * OLLMrpc.Request.register(
		 *     "RPC-Daemon", typeof(Daemon),
		 *     "hello", "is", null
		 * );
		 * OLLMrpc.Request.handlers.set("RPC-Daemon", this.daemon);
		 * }}}
		 *
		 * @param name wire object prefix (e.g. RPC-Folder)
		 * @param type handler GType (C prefix)
		 * @param ... method, signature, …, then null
		 */
		public static void register(
			string name,
			GLib.Type type,
			...
		) {
			if (types == null) {
				types = new Gee.HashMap<string, GLib.Type>();
				methods = new Gee.HashMap<string, Gee.HashMap<string, string>>();
			}
			types.set(name, type);
			if (!methods.has_key(name)) {
				methods.set(name, new Gee.HashMap<string, string>());
			}
			var l = va_list();
			while (true) {
				var method = l.arg<string>();
				if (method == null) {
					break;
				}
				methods.get(name).set(method, l.arg<string>());
			}
		}
```

### 2.2 — Dispatch picks up a listed method

- **🔷** `⏳` `Request.dispatch`: if this prefix + method is in the table, FFI-call it.
- **🔷** That listed-method `if` is a helper: `invoke`. `dispatch` calls it, then `call_*`, then `Gi`.
- **🔷** Unpack with the registered signature. Count must match `request.args.size`.
- **🔷** `lease_id == 0`: `export` the `handlers` default, then `leases.get(id)`. Non-zero `lease_id`: that row.
- **🔷** If the method is **not** listed, emit `call_*` as today. Then `Gi` fallback as today.
- **🔷** 2.2 switch handles `i` and `s` (enough for `hello`). Other letters `GLib.error` until that method is walked.

```vala
		/**
		 * FFI-call a listed instance method.
		 *
		 * @param object_name wire prefix (RPC-Daemon)
		 * @param method_name wire suffix (hello)
		 * @return true when this method is listed
		 */
		private bool invoke(string object_name, string method_name)
		{
			if (methods == null || !methods.has_key(object_name)
				|| !methods.get(object_name).has_key(method_name)) {
				return false;
			}
			var signature = methods.get(object_name).get(method_name);
			var n_extra = 0;
			var offset = 0;
			while (offset < signature.length) {
				var rest = signature.substring(offset);
				if (rest.has_prefix("f")) {
					offset += 1;
					n_extra += 1;
					continue;
				}
				var rest_ptr = (char*) rest;
				var next = (char*) null;
				if (!GLib.VariantType.string_scan(rest, null, out next)
					|| next == rest_ptr) {
					GLib.error("invalid D-Bus type signature %s", signature);
				}
				offset += (int) ((uint8*) next - (uint8*) rest_ptr);
				n_extra += 1;
			}
			if (n_extra != this.args.size) {
				GLib.critical("RPC dispatch: %s args size %d want %d",
					this.method, this.args.size, n_extra);
				return true;
			}
			var self = handlers.get(object_name);
			if (this.lease_id == 0) {
				var id = (int) this.connection.export(self);
				self = this.connection.leases.get(id);
			}
			if (this.lease_id != 0) {
				var id = (int) this.lease_id;
				if (!this.connection.leases.has_key(id)) {
					this.connection.reply_error(
						this, (int) RpcErrorCode.INVALID_PARAMS);
					return true;
				}
				self = this.connection.leases.get(id);
			}
			var camel = new GLib.Regex("(?<=[a-z])([A-Z])");
			var symbol = camel.replace(
				types.get(object_name).name(), -1, 0, "_\\1"
			).down() + "_" + method_name.replace(".", "_");
			var mod = GLib.Module.open(null, GLib.ModuleFlags.BIND_LAZY);
			if (mod == null) {
				GLib.critical("RPC dispatch: Module.open failed for %s",
					this.method);
				return true;
			}
			var fn = (void*) null;
			if (!mod.symbol(symbol, out fn)) {
				GLib.critical("RPC dispatch: no symbol %s for %s",
					symbol, this.method);
				return true;
			}
			var nargs = 2 + n_extra;
			var atypes = new Ffi.Type*[nargs];
			var avalues = new void*[nargs];
			var ivals = new int[n_extra];
			atypes[0] = &Ffi.type_pointer;
			atypes[1] = &Ffi.type_pointer;
			avalues[0] = (void*) self;
			avalues[1] = (void*) this;
			offset = 0;
			var ai = 0;
			while (offset < signature.length) {
				var rest = signature.substring(offset);
				var tag = "";
				if (rest.has_prefix("f")) {
					tag = "f";
					offset += 1;
				} else {
					var rest_ptr = (char*) rest;
					var next = (char*) null;
					if (!GLib.VariantType.string_scan(rest, null, out next)
						|| next == rest_ptr) {
						GLib.error("invalid D-Bus type signature %s",
							signature);
					}
					var n = (long) ((uint8*) next - (uint8*) rest_ptr);
					tag = rest.substring(0, n);
					offset += (int) n;
				}
				switch (tag) {
					case "i":
						ivals[ai] = this.args.get(ai).get_int();
						atypes[2 + ai] = &Ffi.type_sint32;
						avalues[2 + ai] = &ivals[ai];
						break;

					case "s":
						atypes[2 + ai] = &Ffi.type_pointer;
						avalues[2 + ai] = this.args.get(ai).get_string();
						break;

					default:
						GLib.error("unknown D-Bus type %s", tag);
				}
				ai += 1;
			}
			var cif = Ffi.Cif();
			if (Ffi.prep_cif(out cif, Ffi.Abi.DEFAULT_ABI, nargs,
				&Ffi.type_void, atypes) != 0) {
				GLib.critical("RPC dispatch: ffi_prep_cif failed for %s",
					this.method);
				return true;
			}
			Ffi.call(&cif, fn, null, avalues);
			return true;
		}
```
