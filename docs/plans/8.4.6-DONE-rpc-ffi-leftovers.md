## Float / double

- **🔷** `GLib.DataOutputStream` has no `put_float` / `put_double`. Payload is IEEE-754 bits as a BE integer (`put_uint32` / `put_uint64`). Same endian path as today’s ints.
- **🔷** Type bytes are the fundamentals: `GLib.Type.FLOAT` `0x38` (56), `GLib.Type.DOUBLE` `0x3C` (60). No width prefix. No protocol bump.
- **🔷** `convert` / `scalar` `TypeTag.FLOAT` / `DOUBLE` once the wire can carry them.

## Array

- **🔷** Protocol §15 `int[]` **for properties** still uses per-element type byte + payload (Serializable path). `Request.values` uses a different layout: compact count + one **contiguous** fixed-width payload — same idea as `scalar_array` already `Memory.copy`ing from `arg.v_pointer`.
- **🔷** Homogeneous numeric arrays on the wire: `type\|0x80`, compact count, then `count × sizeof(element)` — one **native-endian** contiguous slab (not per-element type bytes).
- **🔷** **Warning (protocol §15):** Do not send numeric arrays across different endianness or CPU arch — native-endian slab. Scalar ints in the same `values[]` list stay BE (§7).
- **🔷** **Write:** private `write_numeric_array` — type\|0x80, compact count, `Memory.copy` into `uint8[count × elem_size]` (or `write_all` from that buffer). Six `typeof(...[])` checks only pick `(fundamental, elem_size, array pointer)`. `elem_size` 4 covers int/uint/float; 8 covers int64/uint64/double (IEEE layout in native order).
- **🔷** **Read:** `read_array` — `read_all` into the typed array backing store via `((uint8[]) …)[0:count × elem_size]`. Switch on fundamental only to pick return type (`int[]` vs `float[]`, …); payload decode is shared.
- **🔷** `string[]` stays inline in `read` / `write` — variable-length elements; not one slab.
- **🔷** `read` delegates other arrays to private `read_array`. `convert_array` / `scalar_array` on `Gi` — `v_pointer` aliases the row; OUT uses `Memory.copy` into a new Vala array.
- **🔷** GIR length companion is a normal IN integer in `values[]` when it is not `is_skip()`. Zero-terminated C `string[]` needs no length slot.
- **💩** `⏳` `ARRAY` edge: length from a sibling OUT arg (`get_array_length()` ≥ 0) — deferred.
- **ℹ️** gnome-shell-rpc 0.5.2 Phase 5 C arrays unblock after this plan.

### Endian transport of numeric arrays

**Warning:** Do **not** send numeric arrays between peers with **different endianness** or **different CPU architectures**. Payloads are a native-endian memcpy — wrong values on the receiver if endian or layout differs. Today: x86_64 LE Linux, `Request.values` / `Response.values` only.

- **Wire:** `type|0x80`, compact count (§9), then `count × sizeof(element)` — one contiguous slab (not per-element type bytes like the property `int[]` example above).
- **Scalar ints** in the same `values[]` list stay **big-endian** (§7) — only the array slab is native-endian.

#### Add — after the closing `}` of `read`, before `read_array` — private slab writer

```vala
		private static void write_numeric_array(
			Stream ctx,
			GLib.Type fundamental,
			int count,
			void* native,
			size_t elem_size
		) throws GLib.Error
		{
			ctx.out_stream.put_byte((uint8) fundamental | 0x80);
			if (count < 128) {
				ctx.out_stream.put_byte((uint8) count);
			} else {
				ctx.out_stream.put_byte((uint8) (0x80 | ((count >> 8) & 0x7F)));
				ctx.out_stream.put_byte((uint8) (count & 0xFF));
			}
			if (count == 0) {
				return;
			}
			var nbytes = count * elem_size;
			var payload = new uint8[nbytes];
			GLib.Memory.copy(payload, native, nbytes);
			size_t written;
			ctx.out_stream.write_all(payload, out written);
		}
```



### 6. `libocrpc/Bin/StreamValue.vala` — `read_array` + `read` delegates

**Why:** `INT | 0x80` today falls into the scalar `INT` case and eats one width byte. Homogeneous decode is one helper so `read` stays a thin dispatcher.

**Where:** new `read_array` after `read`; in `read`, after the `GLib.Type.STRING` block, before `switch ((GLib.Type) (type_byte & 0x7F))`.

**Depends on:** §2, §5.

#### Add — after the closing `}` of `read`, before the closing `}` of the class — contiguous payload after compact count

```vala
		/**
		 * Decode a homogeneous scalar array (type byte has array flag).
		 *
		 * Compact count (§9), then one fixed-width **native-endian** payload slab —
		 * not the per-element type-byte property layout in §15. Same-endian peers only.
		 *
		 * @param ctx active bin session
		 * @param type_byte wire type with bit 7 set
		 * @return array {@link GLib.Value} (''int[]'', ''uint[]'', …)
		 */
		private static GLib.Value read_array(Stream ctx, uint8 type_byte) throws GLib.Error
		{
			var n = ctx.in_stream.read_byte();
			var count = n & 0x7F;
			if ((n & 0x80) != 0) {
				count = (count << 8) | ctx.in_stream.read_byte();
			}
			switch ((GLib.Type) (type_byte & 0x7F)) {
				case GLib.Type.INT:
					var ints = new int[count];
					size_t int_read;
					ctx.in_stream.read_all(
						((uint8[]) ints)[0:count * sizeof(int)], out int_read);
					return ints;

				case GLib.Type.UINT:
					var uints = new uint[count];
					size_t uint_read;
					ctx.in_stream.read_all(
						((uint8[]) uints)[0:count * sizeof(uint)], out uint_read);
					return uints;

				case GLib.Type.INT64:
					var i64s = new int64[count];
					size_t i64_read;
					ctx.in_stream.read_all(
						((uint8[]) i64s)[0:count * sizeof(int64)], out i64_read);
					return i64s;

				case GLib.Type.UINT64:
					var u64s = new uint64[count];
					size_t u64_read;
					ctx.in_stream.read_all(
						((uint8[]) u64s)[0:count * sizeof(uint64)], out u64_read);
					return u64s;

				case GLib.Type.FLOAT:
					var floats = new float[count];
					size_t float_read;
					ctx.in_stream.read_all(
						((uint8[]) floats)[0:count * sizeof(float)], out float_read);
					return floats;

				case GLib.Type.DOUBLE:
					var doubles = new double[count];
					size_t double_read;
					ctx.in_stream.read_all(
						((uint8[]) doubles)[0:count * sizeof(double)], out double_read);
					return doubles;

				default:
					throw new StreamError.PROTOCOL(
						"unsupported bin array type 0x%02X",
						type_byte
					);
			}
		}
```

### 11. `libocrpc/Gi.vala` — `scalar_array`

**Why:** OUT / return C arrays: `Memory.copy` from `arg.v_pointer` into a new Vala array row (same slab semantics as wire decode).

**Where:** after `scalar`, before `boxed_keep` field (or end of class if no other private methods after scalar).

**Depends on:** none.

#### Add — after the closing `}` of `scalar` — zero-terminated UTF8 or fixed-size numeric slab

```vala
		/**
		 * Append one GIR ARRAY return / OUT argument to {@link dest}.
		 *
		 * Zero-terminated UTF8 / FILENAME → ''string[]''. Fixed-size
		 * numeric → typed array via {@link GLib.Memory.copy}.
		 *
		 * @param type GIR array type
		 * @param arg filled by {@link GI.FunctionInfo.invoke}
		 * @param dest {@link Response.values}
		 * @return false when this method already replied an error
		 */
		private bool scalar_array(
			GI.TypeInfo type,
			GI.Argument arg,
			Gee.ArrayList<GLib.Value?> dest
		)
		{
			var elem = type.get_param_type(0);
			var n_arr = type.get_array_fixed_size();
			if (n_arr < 0 && type.is_zero_terminated()
				&& (elem.get_tag() == GI.TypeTag.UTF8 || elem.get_tag() == GI.TypeTag.FILENAME)) {
				string[] strv = {};
				var i = 0;
				while (((string*) arg.v_pointer)[i] != null) {
					strv += ((string*) arg.v_pointer)[i];
					i++;
				}
				dest.add(strv);
				return true;
			}
			if (n_arr < 0) {
				this.request.connection.reply_error(
					this.request, (int) RpcErrorCode.INVALID_PARAMS);
				return false;
			}
			switch (elem.get_tag()) {
				case GI.TypeTag.INT32:
					var ints = new int[n_arr];
					GLib.Memory.copy(ints, arg.v_pointer, n_arr * sizeof(int));
					dest.add(ints);
					return true;

				case GI.TypeTag.UINT32:
					var uints = new uint[n_arr];
					GLib.Memory.copy(uints, arg.v_pointer, n_arr * sizeof(uint));
					dest.add(uints);
					return true;

				case GI.TypeTag.INT64:
					var i64s = new int64[n_arr];
					GLib.Memory.copy(i64s, arg.v_pointer, n_arr * sizeof(int64));
					dest.add(i64s);
					return true;

				case GI.TypeTag.UINT64:
					var u64s = new uint64[n_arr];
					GLib.Memory.copy(u64s, arg.v_pointer, n_arr * sizeof(uint64));
					dest.add(u64s);
					return true;

				case GI.TypeTag.FLOAT:
					var floats = new float[n_arr];
					GLib.Memory.copy(floats, arg.v_pointer, n_arr * sizeof(float));
					dest.add(floats);
					return true;

				case GI.TypeTag.DOUBLE:
					var doubles = new double[n_arr];
					GLib.Memory.copy(doubles, arg.v_pointer, n_arr * sizeof(double));
					dest.add(doubles);
					return true;

				default:
					this.request.connection.reply_error(
						this.request, (int) RpcErrorCode.INVALID_PARAMS);
					return false;
			}
		}
```

```vala

		 * @param response reply being built

			GI.TypeInfo type,
			GI.Argument arg,
			Response response
		)
		{
			var elem = type.get_param_type(0);
			if (elem.get_tag() != GI.TypeTag.INTERFACE) {

					response.result.add(obj);

			}
			for (var node = (GLib.SList) arg.v_pointer; node != null; node = node.next) {
```

```vala

		 * Export each GObject value from a GIR GHASH return.
		 *
		 * Only ''UTF8'' keys and registered GObject values. Null table →
		 * empty {@link Response.result}. Iteration order is undefined.
		 *
		 * @param type GIR hash type
		 * @param arg filled by {@link GI.FunctionInfo.invoke}
		 * @param response reply being built
		 * @return false when this method already replied an error

			GI.TypeInfo type,
			GI.Argument arg,
			Response response
		)
		{
			var key_type = type.get_param_type(0);
			var val_type = type.get_param_type(1);

					this.request, (int) RpcErrorCode.INVALID_PARAMS);
				return false;

			var kind = val_type.get_interface().get_type();
			if (kind != GI.InfoType.OBJECT && kind != GI.InfoType.INTERFACE) {
				this.request.connection.reply_error(
					this.request, (int) RpcErrorCode.INVALID_PARAMS);
				return false;

				return true;

			var ht = (GLib.HashTable<string, GLib.Object>) arg.v_pointer;
			foreach (var key in ht.get_keys()) {

				if (Bin.gtype_to_alias == null || !Bin.gtype_to_alias.has_key(obj.get_type())) {
					this.request.connection.reply_error(
						this.request, (int) RpcErrorCode.INVALID_PARAMS);

				this.request.connection.export(obj);
```
