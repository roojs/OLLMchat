## Bug

This is the **live-handle** path (lease id on the wire), **not** full `Bin.Serializable` property dump.

`Gi.register("Meta", "16")` puts typelib object GTypes into `Bin.gtype_to_alias` (e.g. `Meta-WindowActor`, `Meta-Compositor`).

Mutter often returns **concrete subclasses** that are **not** in the typelib:

- `MetaWindowActorX11` — not in `Bin.gtype_to_alias` (private subclass)
- `MetaWindowActor` — yes, via `Gi.register`
- `MetaCompositorServer` — not in the map
- `MetaCompositor` — yes, via `Gi.register`

Live returns still need a registered alias:

1. **`Gi.scalar_list` / GObject return** — exact `has_key(obj.get_type())` or `INVALID_PARAMS` (never `export` / never put on `result`).
2. **`Response.result` array header** — `write_gtype` / `write_reg_gtype` for the **element schema name**; each row is still only a lease id + `TOKEN_END`. Concrete type missing → `Unregistered class type schema: MetaWindowActorX11` (same class of failure as `MetaCompositorServer`).

So: **lease payload is fine**; the **type tag / alias** that names the client stub class is what breaks.

In-process mutter still has the actors (`get_window_actors` length 1, type `MetaWindowActorX11`). The RPC path drops them.

**Repro (nested, gnome-shell-rpc):**

```text
Meta-Display.get_compositor → lease (hand values path; concrete MetaCompositorServer)
Meta-Compositor.get_window_actors → Gi.dispatch
  server log: window_actors n=1 type=MetaWindowActorX11
  client: empty list / INVALID_PARAMS (no MetaWindowActorX11 alias)
```

## Goal

- **🔷** Consumer **manually** registers each concrete server `GType` they intend to lease, mapping it to an **existing** typelib wire alias (the client stub type).
- **🔷** Example (server boot, after `Gi.register("Meta", "16")` and mutter types exist):
  - `MetaWindowActorX11` → wire alias `Meta-WindowActor`
  - `MetaCompositorServer` → wire alias `Meta-Compositor`
- **🔷** Wire **payload** stays lease id. Client still `Object.new` the typelib stub (`alias_to_gtype` unchanged). Server lease still holds the real subclass.
- **🔷** Lookup on write / `scalar_list` stays **exact** `gtype_to_alias.has_key(obj.get_type())`. No inference.
- **🔷** Wrong or missing manual entries fail loud (`INVALID_PARAMS` / unregistered schema).

Intro: edits are **Remove** / **Replace with** / **Add** from the tree;
verify surrounding context before applying.

## Fix sites

**ℹ️** `Gi.scalar_list` / `write_gtype` / `write_reg_gtype` — **no fence**. Exact map only.

**🔷** Dedicated hook, not a second `Bin.register` of the same alias. `register` still throws on duplicate alias so the stub GType cannot be overwritten.

**💩** Argument order matches `Bin.register(alias, gtype)` (not `(gtype, alias)`).

### 1. `libocrpc/Bin/Stream.vala` — `register_alias`: extra GType → existing alias

**Why:** Many server GTypes, one wire alias. `alias_to_gtype` stays the typelib stub from `register` / `Gi.register`.

**Where:** after `register`, before the `Stream` class.

**Depends on:** none.

**🔷** Method name: `register_alias` (plan / this hook).

#### Add — after the closing `}` of `register`

```vala
	/**
	 * Map an extra server GType to an alias already passed to
	 * {@link register}.
	 *
	 * Does not change {@link alias_to_gtype}. The client still
	 * {@link GLib.Object.new} the stub type. Call after the typelib
	 * alias exists (usually {@link OLLMrpc.Gi.register}) and after
	 * the concrete GType is loaded ({@link GLib.Type.from_name}).
	 * The concrete list is the consumer's (X11 vs Wayland differ).
	 *
	 * == Example ==
	 *
	 * {{{
	 * OLLMrpc.Gi.register("Meta", "16");
	 * OLLMrpc.Bin.register_alias("Meta-WindowActor",
	 *     GLib.Type.from_name("MetaWindowActorX11"));
	 * }}}
	 *
	 * @param alias wire type name already in {@link alias_to_gtype}
	 * @param gtype extra server GType that should encode as ''alias''
	 * @throws StreamError.REGISTRATION unknown alias, invalid
	 *     ''gtype'', or ''gtype'' already mapped
	 */
	public static void register_alias(string alias, GLib.Type gtype) throws GLib.Error
	{
		if (gtype == GLib.Type.INVALID) {
			throw new StreamError.REGISTRATION("invalid gtype for alias '%s'", alias);
		}
		if (alias_to_gtype == null || !alias_to_gtype.has_key(alias)) {
			throw new StreamError.REGISTRATION("unknown alias '%s'", alias);
		}
		if (gtype_to_alias.has_key(gtype)) {
			throw new StreamError.REGISTRATION("duplicate register of type '%s'", gtype.name());
		}
		gtype_to_alias.set(gtype, alias);
	}
```
