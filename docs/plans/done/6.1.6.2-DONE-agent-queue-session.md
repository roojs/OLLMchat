## Purpose

- ✅ Agent Pi activate: bind strip `MessageQueue.items = session.queued_messages`; share that **same** `MessageQueue` with the agent; emit **`MessageQueue.can_queue(true)`** (signal relay — MessageQueue does **not** store the flag).
- ✅ Agent Pi deactivate: emit **`MessageQueue.can_queue(false)`** — strip disappears. Session `queued_messages` stay; do not empty `items`.
- ✅ `MessageQueue` is the shared relay Agent and Chat both use (libollmchat). ChatWidget hooks the strip’s queue at create time: on `can_queue` signal → set `ChatWidget.can_queue` + strip visibility; on `items_changed` → refresh visibility.
- ✅ Height: keep `propagate_natural_height` + modest `max_content_height` (already in `MessageQueueView`).
- ℹ️ Agent change → new session: **[`6.1.6.3-DONE-agent-session-switch.md`](6.1.6.3-DONE-agent-session-switch.md)** (out of this plan).
- ℹ️ Window / `ChatDesktopInterface` only exposes **`chat_message_queue()`** (like `above_input_widget`) — **not** `can_queue`. Factory cast variable: **`ui`**.
- ℹ️ Bind path follows [`7.14.5-DONE-skill-progress-session-bind.md`](7.14.5-DONE-skill-progress-session-bind.md): work in `Factory.activate` / `deactivate`; restore reuses `session_restored` → `factory.activate`.

## Queue strip (visibility + height) + MessageQueue relay

- 🔷 Show only when `ChatWidget.can_queue` and `queue.get_n_items() > 0` (flag lives on the chat widget; queue only signals).
- ℹ️ Scrolled already: `set_propagate_natural_height(true)` + `set_max_content_height(160)` — keep; do not copy ProgressView’s 288px min.
- 🔷 `MessageQueue` emits `can_queue(bool)` — no property / no stored enable bit on the queue.

### 1. `libollmchat/MessageQueue.vala` — `can_queue` signal

**Why:** Relay enable/disable from Agent Pi to chat UI without gtk types and without holding UI state on the queue.

**Where:** class body after `items` property.

**Depends on:** none.

#### Add — After the `items` property block.

```vala
		/**
		 * Relay: Agent / Factory emit to toggle mid-run composer + strip.
		 * ChatWidget connects; this class does not store the flag.
		 *
		 * @param enabled whether mid-run queuing is on
		 */
		public signal void can_queue(bool enabled);
```

### 2. `libollmchatgtk/MessageQueueView.vala` — hook `can_queue` + `items_changed`

**Why:** Strip created with the chat window; listen on the owned `MessageQueue` and drive `ChatWidget.can_queue` + visibility.

**Where:** end of constructor, after `this.append(scrolled)`.

**Depends on:** §1.

#### Add — After `this.append(scrolled);`.

```vala
			this.queue.can_queue.connect((enabled) => {
				this.chat_widget.can_queue = enabled;
				this.visible = enabled && this.queue.get_n_items() > 0;
			});
			this.queue.items_changed.connect((position, removed, added) => {
				this.visible = this.chat_widget.can_queue
					&& this.queue.get_n_items() > 0;
			});
```

## Host surface (ChatDesktopInterface → Window)

- 🔷 Factory gets the strip model via `chat_message_queue()` only (same idea as `above_input_widget`).
- 🔷 No `can_queue` on the window / desktop interface — that lives on `MessageQueue` + `ChatWidget`.

### 3. `libollmchat/ChatDesktopInterface.vala` — `chat_message_queue()`

**Why:** Agent Pi needs the strip `MessageQueue` without importing gtk chat types.

**Where:** interface body after `above_input_widget()`.

**Depends on:** none.

#### Add — After `above_input_widget()` declaration.

```vala
		/**
		 * Pending-queue ListModel owned by the chat strip (never swap the
		 * ColumnView model — only assign {@link MessageQueue.items}; emit
		 * {@link MessageQueue.can_queue} to enable/disable).
		 *
		 * @return strip MessageQueue
		 */
		public abstract MessageQueue chat_message_queue();
```

### 4. `ollmapp/Window.vala` — implement `chat_message_queue()`

**Why:** Forward to `chat_widget.queue_view.queue`.

**Where:** class body next to `above_input_widget()`.

**Depends on:** §3.

#### Add — After `above_input_widget()` method.

```vala
		/* ChatDesktopInterface.chat_message_queue */
		public OLLMchat.MessageQueue chat_message_queue()
		{
			return this.chat_widget.queue_view.queue;
		}
```

## Bind sites (Agent Pi)

- 🔷 Follow 7.14.5: bind in `AgentPi.Factory.activate` / `deactivate`; session restore already calls `factory.activate` via `session_restored`.
- 🔷 One ListModel: after bind, `agent.message_queue` **is** `ui.chat_message_queue()`.

### 5. `liboccoder/AgentPi/Agent.vala` — `message_queue` settable by Factory

**Why:** Factory must point the agent at the strip’s `MessageQueue` so `append` updates the UI.

**Where:** `message_queue` property.

**Depends on:** none.

#### Remove

```vala
		public OLLMchat.MessageQueue message_queue {
			get; private set;
		}
```

#### Replace with

```vala
		public OLLMchat.MessageQueue message_queue {
			get; internal set;
		}
```

### 6. `liboccoder/AgentPi/Factory.vala` — `activate`: bind queue

**Why:** Share strip ListModel with the session agent; enable via `can_queue` signal.

**Where:** `activate` — rename local `host` → `ui`; after `ui.schedule_pane_update(true);`.

**Depends on:** §1–§5.

##### Part 1 — cast name

#### Remove

```vala
			var host = (OLLMchat.ChatDesktopInterface) window;
```

#### Replace with — In `activate` (and the same rename in `deactivate`).

```vala
			var ui = (OLLMchat.ChatDesktopInterface) window;
```

ℹ️ Also replace every `host.` in these two methods with `ui.` (existing SourceView / pane lines).

##### Part 2 — bind after pane update

#### Add — After `ui.schedule_pane_update(true);` in `activate`.

```vala
			var agent = (Agent) ui.session_agent();
			var queue = ui.chat_message_queue();
			queue.items = agent.session.queued_messages;
			queue.can_queue(true);
			agent.message_queue = queue;
```

### 7. `liboccoder/AgentPi/Factory.vala` — `deactivate`: emit `can_queue(false)`

**Why:** Leaving Agent Pi turns off mid-run composer / strip (ChatWidget hears the signal). Does **not** clear `session.queued_messages`.

**Where:** `deactivate` body.

**Depends on:** §1–§4.

#### Remove

```vala
		public override async void deactivate(GLib.Object window)
		{
			var host = (OLLMchat.ChatDesktopInterface) window;
			host.schedule_pane_update(false);
		}
```

#### Replace with

```vala
		public override async void deactivate(GLib.Object window)
		{
			var ui = (OLLMchat.ChatDesktopInterface) window;
			ui.chat_message_queue().can_queue(false);
			ui.schedule_pane_update(false);
		}
```
