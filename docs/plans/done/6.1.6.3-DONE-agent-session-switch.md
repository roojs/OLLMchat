## Purpose

- ✅ User agent pick when `manager.session is Session` → create new session, keep draft, activate chosen agent.
- ✅ Still `EmptySession`: in-place `activate_agent`.
- ✅ Programmatic dropdown sync uses `block_select_signal` / `select_only` (restore must not fork).
- ✅ Named helper on `AgentDropdown`: **`select_only`**. Name→row via **`ListStore.find`** (same factory instance as in the model).
- ✅ `activate_agent` warns on failure itself — callers do **not** try/catch.
- ℹ️ Queue bind / `can_queue` signal: **6.1.6.2**.

## Agent switch → new session

- 🔷 Predicate: `session is OLLMchat.History.Session` (not `EmptySession`) — keep in dropdown; do not invent an `activate_agent` flag for this.
- 🔷 User picks: unblocked `notify["selected"]`.
- 🔷 Programmatic sync: caller uses `select_only` (`block_select_signal`).

---

### 0. `activate_agent` — warn inside, no `throws`

**Why:** Dropdown (and fork path) only ever logged a warning on failure. Push that into the method so call sites stay flat.

**Where:** `SessionBase` abstract + `Session` / `EmptySession` / `SessionPlaceholder` overrides; `Manager.activate_agent` if it still wraps.

**Depends on:** none.

#### Remove — `SessionBase` abstract signature

```vala
		public abstract void activate_agent(string agent_name) throws Error;
```

#### Replace with

```vala
		/**
		 * Activates an agent for this session.
		 *
		 * On failure logs {@link GLib.warning} and returns — callers do not
		 * try/catch.
		 *
		 * @param agent_name The name of the agent to activate
		 */
		public abstract void activate_agent(string agent_name);
```

#### Change — `Session.activate_agent` / `EmptySession.activate_agent`

- Drop `throws Error` from the override signature.
- Wrap the body in `try { … } catch (GLib.Error e) { GLib.warning("Failed to activate agent '%s': %s", agent_name, e.message); }` (or equivalent around the parts that can fail).
- Keep existing success-path logic unchanged.

#### Change — `SessionPlaceholder.activate_agent`

- Drop `throws Error` only (body already no-op).

#### Change — `Manager.activate_agent`

- Stop declaring `throws Error` for the delegate path, **or** catch/warn when calling `session.activate_agent`.
- Missing-fid case: warn + return (same “cheap warning” policy), do not force callers to catch.

ℹ️ After this, **no** try/catch around `activate_agent` in `AgentDropdown`.

### 1. `ollmapp/AgentDropdown.vala` — block flag + `select_only`

**Why:** Restore / `session_activated` must set the dropdown without running the user-pick fork.

**Where:** fields + after `selected` property; callers of programmatic select use `select_only`.

**Depends on:** §0 (so Part 2 has no try/catch).

##### Part 1 — field + `select_only`

#### Add — After `private Gtk.SignalListItemFactory list_factory;`.

```vala
		private bool block_select_signal = false;
```

#### Add — After the `selected` property block.

```vala
		/**
		 * Programmatic selection only (restore / session sync). Blocks
		 * {@link notify} handler — use instead of {@link selected} when
		 * syncing UI to an existing session.
		 *
		 * @param index agent row index in the dropdown model
		 */
		public void select_only(uint index)
		{
			this.block_select_signal = true;
			this.dropdown.selected = index;
			this.block_select_signal = false;
		}
```

ℹ️ Name→row: use {@link GLib.ListStore.find} with the factory instance — **do not** add an `index_of` / `find` helper.

##### Part 2 — `wire`: guard + fork + blocked initial/sync selects

**Why:** User pick forks on real `Session`; restore paths must not.

**Where:** whole `notify["selected"]` handler and the two programmatic `selected =` sites in `wire`.

**Depends on:** Part 1, §0.

#### Remove

```vala
			this.dropdown.notify["selected"].connect(() => {
				if (this.dropdown.selected == Gtk.INVALID_LIST_POSITION) {
					return;
				}

				var factory = (this.dropdown.model as GLib.ListStore)
					.get_item(this.dropdown.selected)
					as OLLMchat.Agent.Factory;
				this.dropdown.tooltip_text = factory.long_title;

				try {
					if (this.host.history_manager.session.fid == null
					    || this.host.history_manager.session.fid == "") {
						this.host.history_manager.session.activate_agent(
							factory.name);
						return;
					}
					this.host.history_manager.activate_agent(
						this.host.history_manager.session.fid, factory.name);
				} catch (GLib.Error e) {
					GLib.warning(
						"Failed to activate agent '%s': %s",
						factory.name, e.message);
				}
			});

			this.dropdown.selected = selected_index;

			this.host.history_manager.session_activated.connect((session) => {
				var store = this.dropdown.model as GLib.ListStore;
				if (store == null) {
					return;
				}
				var factory = this.host.history_manager.get_active_agent();
				factory.activate.begin(this.host, (obj, res) => {
					factory.activate.end(res);
				});
				uint agent_index = 0;
				for (uint j = 0; j < store.get_n_items(); j++) {
					if (((OLLMchat.Agent.Factory) store.get_item(j)).name
					    == session.agent_name) {
						agent_index = j;
						break;
					}
				}
				if (this.session_selection(session, agent_index)) {
					return;
				}
				this.selected = agent_index;
			});
```

#### Replace with

```vala
			this.dropdown.notify["selected"].connect(() => {
				if (this.block_select_signal) {
					return;
				}
				if (this.dropdown.selected == Gtk.INVALID_LIST_POSITION) {
					return;
				}

				var factory = (this.dropdown.model as GLib.ListStore)
					.get_item(this.dropdown.selected)
					as OLLMchat.Agent.Factory;
				this.dropdown.tooltip_text = factory.long_title;

				var session = this.host.history_manager.session;
				if (!(session is OLLMchat.History.Session)) {
					session.activate_agent(factory.name);
					return;
				}

				var draft = this.host.chat_widget.chat_input.text();
				var empty = this.host.history_manager.create_new_session();
				empty.project_path = session.project_path;
				this.host.chat_widget.switch_to_session.begin(empty, (obj, res) => {
					this.host.chat_widget.switch_to_session.end(res);
					empty.activate_agent(factory.name);
					/* session_activated may have selected the copied
					 * old agent_name — put the dropdown back on the pick. */
					var agent_index = 0u;
					var store = (GLib.ListStore) this.dropdown.model;
					store.find(factory, out agent_index);
					this.select_only(agent_index);
					if (draft.length > 0) {
						this.host.chat_widget.chat_input.update_entry(draft);
					}
				});
			});

			this.select_only(selected_index);

			this.host.history_manager.session_activated.connect((session) => {
				var factory = this.host.history_manager.get_active_agent();
				factory.activate.begin(this.host, (obj, res) => {
					factory.activate.end(res);
				});
				var agent_index = 0u;
				var store = (GLib.ListStore) this.dropdown.model;
				store.find(factory, out agent_index);
				if (this.session_selection(session, agent_index)) {
					return;
				}
				this.select_only(agent_index);
			});
```

## LLM notes

- 🚫 Do not use `factory.name == session.agent_name` as the restore guard — callers who set selection must `select_only` / `block_select_signal`.
- 🚫 Do not put the fork in `Manager.activate_agent` / `Session.activate_agent` alone.
- 🚫 Do not add an `empty_only` / `session_only` flag to `activate_agent` — keep `is Session` in the dropdown.
- 🚫 Do not try/catch `activate_agent` in the UI — warning lives in §0.
- 🚫 Do not implement MessageQueue / Agent Pi queue bind here — that is **6.1.6.2**.
- 🚫 Do not add `index_of` / custom `find` helpers — use **`ListStore.find`**.
