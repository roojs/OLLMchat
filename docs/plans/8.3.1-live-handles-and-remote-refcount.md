## Purpose

- **🔷** `✔️` When `live_handles` is on, the server holds a GObject until the client unrefs the proxy, or the socket dies. Flag off: no table use, no `RPC-Live-Remote.unref`.
- **🔷** `✔️` Per-`Connection` table: `Gee.HashMap<int, …>` (plus a ref the table owns). Empty maps always exist. Unused when the flag is off.
- **🔷** `✔️` Gee has no working hash for `uint64` keys. Wire id stays `uint64`; cast to `int` at the map. Reverse lookup is `HashMap<string, int>` keyed by hex of the instance pointer (`to_string("%" + uint64.FORMAT_MODIFIER + "x")`), not a GObject key.
- **🔷** `✔️` `Connection.export` allocates ids when the server first exports an instance. Reuse the same id while the object is still leased to that connection.
- **🔷** `✔️` Record GObject `ref_count` at handle creation as the **floor**. The table’s extra ref sits above that floor.
- **🔷** `✔️` Wire methods `RPC-Live-Remote.ref` / `RPC-Live-Remote.unref`. gnome-shell-rpc `RemoteRef` / `RemoteUnref` names map to these.
- **🔷** `✔️` `RPC-Live-Remote.ref` — client takes an extra ref it owns.
- **🔷** `✔️` `RPC-Live-Remote.unref` — drops a client-owned extra first. At extra 0, drops the export hold only. Must not drive the GObject below the creation floor. Does not destroy the domain object.
- **🔷** `✔️` `Connection.stop()` / HUP: unref every lease on that connection (each drop still respects the floor).
- **🔷** `✔️` Smoke in `tests/rpc/live-handles-test.vala` — dummy `GLib.Object`. No mutter types.
- **🔷** `✔️` Phase 1 handle on the wire is `uint64 object_id` on `RemoteParams`. Nested live-object encode is [`8.3.3`](8.3.3-notification-gobject-payload.md).

## LLM notes

- Do not use `Gee.HashMap<uint64, …>`. Reverse index is `HashMap<string, int>` of pointer hex, not `HashMap<GLib.Object, int>`.
- Unset `lease_ids` **before** `leases.unset` in `RPC-Live-Remote.unref` (need the object to build the hex key). Keep `leases.get(id)` in a GObject local — casting the owned `get()` to `void*` leaks that ref.
- `leases.unset` / `clear()` drops the table hold — do not extra `unref` that. `stop()` drops extras then `clear()`s all maps.
- Handler wiring is `Request.register("RPC-Live-Remote", new Live.Remote(), typeof(Live.RemoteParams))` at server boot (tests / mutter plugin), same as ollmfilesd `Application`. Types live in `OLLMrpc.Live`. Wire prefix is `RPC-Live-Remote`.
