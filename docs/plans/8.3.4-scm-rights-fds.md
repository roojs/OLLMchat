## Purpose

- **🔷** `⏳` Pass a dmabuf (or other) fd with a notification or response. No texture pixel dump on the bin socket.
- **🔷** `⏳` Unix `Connection` only. TCP/stdio stay without fds.
- **🔷** `⏳` Wire: bin message names the fd; ancillary data carries the fd on the same `sendmsg`.
- **🔷** `⏳` Tests with a pipe or memfd, not mutter.
- **ℹ️** gnome-shell-rpc Phase 4 overview thumbnails consume this. Implement here first so they are not blocked on inventing a second fd protocol.
- **ℹ️** ollmfilesd does not need this for general work.
