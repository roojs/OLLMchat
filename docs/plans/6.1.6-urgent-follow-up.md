## Loop (reminder)

```
prompt(user)
  loop:
    [drain urgent → inject as user msgs]
    stream assistant
    if toolCalls → run tools → continue
    else if follow-ups → inject → continue
    else stop
```

- 🔷 Post-tool: `FilterListModel` role `"urgent"`; take **most recent** (`get_n_items() - 1`).
- 🔷 At stop: drain **whole** queue in list order.
- 🔷 Escalate: `role = "urgent"` only (no insert / reorder).
