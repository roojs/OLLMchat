## Purpose

Bits pulled out of 8.4.2 / 8.4.3 so those plans stay **DONE**. Extra `convert` tags and `append` were never first-smoke. The invoke return pointer **is** — `Gio-Menu.new` can still lose the constructor object.

- **🔷** `⏳` `fn.invoke` `return_value` is by value in the system vapi. `out` / `ref` fail. Passing `ret` discards the constructor pointer. A pointer-passing binding is still unapproved. Name it here when we do it.
- **🔷** `⏳` GI has no `TypeTag.OBJECT`. GObject returns are `INTERFACE`. [`8.4.3`](8.4.3-DONE-rpc-ffi-typelib-method.md) fenced `OBJECT` | `INTERFACE`. The `OBJECT` branch does not compile.
- **🔷** `⏳` `convert` / `scalar` still `INVALID_PARAMS` for `INTERFACE`, `ARRAY`, float. Constructor-with-args (`Gio-SimpleAction.new`) and `append` wait on `INTERFACE`.
- **ℹ️** Invoke throw → client is [`8.4.4`](8.4.4-rpc-invoke-errors.md).

No fences until the invoke-return binding name is confirmed.

---

## Invoke return

- **ℹ️** [`8.4.2`](8.4.2-DONE-rpc-ffi-typelib-invoke.md) LLM note: vapi `GI.Argument return_value` by value. Both `out` and `ref` fail at valac.
- **🔷** `⏳` Constructor / method GObject pointer must come back from `invoke`. Without a pointer, `export` sees null.
- **💩** Local C / `[CCode]` wrapper that takes `GI.Argument*` — user must name it. Do not add `invoke_raw` until then.

---

## Return tag

- **🔷** `⏳` In `dispatch_function`, GObject returns: `GI.TypeTag.INTERFACE` only. Drop `TypeTag.OBJECT`.

---

## More `convert` / `scalar` tags

- **🔷** `⏳` `INTERFACE` — object-valued IN args and constructor args (`Gio-SimpleAction.new`, `Gio-Menu.append`). Lease id in `values`, or a live GObject already on the connection.
- **💩** `⏳` `GValue.transform` into the GIR width (wire `INT` → tag `INT64`) — inside `convert`, not a second helper.
- **ℹ️** `FLOAT` / `DOUBLE` / `ARRAY` stay `INVALID_PARAMS` until `StreamValue` can carry them.
