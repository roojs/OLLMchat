# 8.4.2 — Typelib register, remote `new`, invoke on handle

> **`docs/plans/1.0-summary.md` is not updated** for this sub-plan until it is done and archived.

**Status:** **PROPOSED**

**Parent:** [`8.4-rpc-positional-values-and-ffi.md`](8.4-rpc-positional-values-and-ffi.md)

**Depends on:** [`8.4.1`](8.4.1-rpc-positional-values.md) (`Request.values` as `GLib.Value`s).

**Already in tree:** `Connection.export` / leases (`Live.Remote` ref/unref), client `proxies` (`tests/rpc/live-handles-test.vala`, `tests/rpc/proxies-test.vala`).

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**; proposed Vala follows **`docs/coding-standards.md`**

---

## Purpose

- **🔷** `⏳` End goal: the client can call **any method in the loaded typelib** on a live server object, identified by handle.
- **🔷** `⏳` Phase 1 — load the typelib and register every object type.
- **🔷** `⏳` Phase 2 — RPC `new` on that type (no handle): server constructs, leases, returns a handle.
- **🔷** Land Phase 1 and Phase 2 together. Register-only is not a shippable slice; the first proof is `Gio-Menu.new`.
- **🔷** `⏳` Phase 3 — RPC any other method on that handle: server looks up the lease, invokes via the typelib.
- **🔷** Handled objects on the RPC path do **not** dump properties on the wire. If the client wants properties, it asks later (not this plan).
- **ℹ️** Existing `Request.register` / `call_*` handlers (ollmfilesd) stay. Typelib types are a second dispatch path when the prefix is not a handler singleton.

Intro: edits are **Remove** / **Replace with** / **Add** from the tree;
verify surrounding context before applying.

---

## Shape

- **🔷** Wire method: `{alias}.{method}` — alias is typelib namespace + hyphen + object name (`Gio-Menu.new`, `Gio-Menu.get_n_items`).
- **🔷** Phase 2 `new` is type-level: **no handle** on the request. Constructor args (if any) are `Request.values` in GIR order.
- **🔷** Phase 3 instance calls use the **same envelope** plus a handle that names the lease. `values` are the GIR arguments after the instance.
- **ℹ️** `Request.dispatch` today only looks up `handlers` singletons and emits `call_*`. Typelib types are not singletons — both `new` and later instance methods go through a GI intercept when the prefix is in `Gi.types`.
- **🔷** A handled object on the wire is type alias + handle id, **not** a property snapshot.

**Dispatch order (Phases 2–3 share this):**

- **ℹ️** If `handlers` has the prefix → today's `call_*` (ollmfilesd). Unchanged.
- **🔷** Else if `Gi.types` has the prefix and method is `new` → Phase 2 construct / export / reply.
- **🔷** Else if `Gi.types` has the prefix and a handle is set → Phase 3 lookup lease / `find_method` / invoke / reply.
- **ℹ️** Else today's critical (unknown handler).

## Phase 1 — Load typelib, register object types

- **🔷** `⏳` `GI.Repository.require` the namespace (installed `Gio-2.0` is the first consumer).
- **🔷** `⏳` Walk `get_n_infos` / `get_info`. Register each `GI.InfoType.OBJECT` that has a `GType`.
- **🔷** `⏳` Wire alias: `namespace + "-" + info.get_name()` (`Gio-Menu`, `Gio-SimpleAction`).
- **🔷** `⏳` `Bin.register(alias, gtype)` so the type can appear on the wire later.
- **🔷** `⏳` Keep a `Gi.types` map (`alias` → `GLib.Type`) for Phase 2 / 3 dispatch. Skip `GType.INVALID`. Skip a second `Bin.register` of the same alias (`alias_to_gtype.has_key`).
- **🔷** No Phase 1 test. Register-only `has_key` asserts do not prove RPC. First smoke is Phase 2 `Gio-Menu.new`.
- **ℹ️** Unix-only (same gate as `Live/` — no GI on the Windows/Android libocrpc cut).
- **ℹ️** Vala `GI.ObjectInfo` does not inherit `RegisteredTypeInfo` in the vapi. C still is one struct — cast to `GI.RegisteredTypeInfo` and call `get_g_type()` (runs `type_init`). If valac rejects the cast, `GLib.Type.from_name(obj.get_type_name())` after require.

```vala
namespace OLLMrpc
{
	/**
	 * Register GObject types from a typelib for RPC dispatch.
	 *
	 * {@link register} requires the namespace, then maps every object
	 * type to a wire alias ({@link Bin.register}) so a client can call
	 * ''Alias.new'' with no handle, then other methods on the lease.
	 * Construction and invoke land in {@link Request.dispatch}.
	 *
	 * == Example ==
	 *
	 * {{{
	 * OLLMrpc.Gi.register("Gio", "2.0");
	 * var req = new OLLMrpc.Request() {
	 *     method = "Gio-Menu.new"
	 * };
	 * }}}
	 */
	public class Gi : GLib.Object
	{
		/**
		 * Wire alias → GType for typelib objects (''Gio-Menu'').
		 */
		public static Gee.HashMap<string, GLib.Type> types;

		/**
		 * Require ''ns'' / ''version'' and register each object GType.
		 *
		 * Alias is ''ns-Name'' (hyphen, same style as ''RPC-Live-Remote'').
		 * Skips infos that are not objects, or have no GType. A second
		 * register of the same alias is a no-op.
		 *
		 * @param ns typelib namespace (''Gio'', ''Meta'')
		 * @param version typelib version (''2.0'', ''16'')
		 * @throws GLib.Error when {@link GI.Repository.require} fails
		 */
		public static void register(string ns, string version) throws GLib.Error
		{
			if (types == null) {
				types = new Gee.HashMap<string, GLib.Type>();
			}
			GI.Repository.get_default().require(ns, version, 0);
			var n = GI.Repository.get_default().get_n_infos(ns);
			for (var i = 0; i < n; i++) {
				var info = GI.Repository.get_default().get_info(ns, i);
				if (info.get_type() != GI.InfoType.OBJECT) {
					continue;
				}
				var registered = (GI.RegisteredTypeInfo) info;
				var gtype = registered.get_g_type();
				if (gtype == GLib.Type.INVALID) {
					continue;
				}
				var alias = ns + "-" + info.get_name();
				if (Bin.alias_to_gtype != null && Bin.alias_to_gtype.has_key(alias)) {
					types.set(alias, gtype);
					continue;
				}
				Bin.register(alias, gtype);
				types.set(alias, gtype);
			}
		}
	}
}
```

## Phase 2 — RPC `new` (no handle)

Goal: the client can create a live object on the server and get a handle back. No instance methods yet. Implement with Phase 1.

**Call:**

- **🔷** `⏳` `method = "Gio-Menu.new"`.
- **🔷** No handle on the request (`new` is type-level).
- **🔷** `values` are constructor args in GIR order. First smoke is zero-arg (`values` empty).
- **💩** Constructor-with-args (`Gio-SimpleAction.new`) is a follow-up in the same `dispatch` branch, not a new API.

**Server:**

- **🔷** `⏳` `Request.dispatch`: if `handlers` has the prefix, today's `call_*`. Else if `Gi.types` has the prefix and method is `new`, construct / export / reply. Unix-only (`#if !G_OS_WIN32 && !ANDROID`); Windows/Android keep today's handler-only path.
- **🔷** `⏳` `ObjectInfo.find_method("new")`. Must be `GI.FunctionInfoFlags.IS_CONSTRUCTOR`.
- **🔷** `⏳` `FunctionInfo.invoke` with **no** instance pointer. Pack `Request.values` into `GI.Argument[]` inline in `dispatch`.
- **🔷** `⏳` `request.connection.export(obj)` then `request.reply` with that object in `Response.result`.
- **🔷** `new` requires `connection.live_handles`. Otherwise `reply_error` (`INVALID_PARAMS`).

**Return (type + handle, no properties):**

- **ℹ️** `Response.result` today casts each row to `Bin.Serializable` and dumps properties. A Gio instance is not `Serializable`.
- **🔷** When `Stream.live_handles` is on and the row type is **not** `Serializable`: array header still `write_gtype`; each body is `uint64` handle (big-endian, `put_uint64` / `read_uint64`) + `TOKEN_END`. No property tags.
- **🔷** `Serializable` rows in the same `result` list stay on today's `bin_write` path (ollmfilesd unchanged).
- **🔷** Decode: `Object.new(gtype)`, `proxies.set(handle, obj)`, consume `TOKEN_END`. `parse_object` returns `GLib.Object` (root `parse()` still casts to `Serializable`).
- **🔷** `Stream.lease_ids` is the same map as `Connection.lease_ids` (assigned when creating `bin`). `Stream.proxies` is the same map as `Client.proxies`.

**Smoke** (first test binary — `tests/rpc/gi-test.vala` + meson `test-rpc-gi`):

- **🔷** `⏳` Listen + client with `live_handles = true`. `Gi.register("Gio", "2.0")` once (same process). `RPC-Daemon.hello` like `values-test.vala`.
- **🔷** `⏳` `Gio-Menu.new`. Assert `response.result.size == 1`, `rpc.proxies.size == 1`, handle ≠ 0, proxy is the result object.
- **🔷** `⏳` Do **not** call a method on it yet — that is Phase 3.

Phase 2 does **not** add `Request.object_id` — that is Phase 3.

```vala
			}

```

##### Replace with

```vala
			if (handlers != null && handlers.has_key(object_name)) {
				var handler = handlers.get(object_name);
				var signal_name = "call_" + method_name.replace(".", "_");
				if (GLib.Signal.lookup(signal_name, handler.get_type()) == 0) {
					GLib.critical(
						"RPC dispatch: no signal call_%s on %s for %s",
						method_name.replace(".", "_"),
						object_name,
						this.method
					);
					return false;
				}
				GLib.debug("emit %s id=%d", signal_name, this.id);
				GLib.Signal.emit_by_name(handler, signal_name, this);
				GLib.debug("emit returned id=%d", this.id);
				return true;
			}
#if !G_OS_WIN32 && !ANDROID
			if (Gi.types != null && Gi.types.has_key(object_name)
				&& method_name == "new") {
				if (!this.connection.live_handles) {
					this.connection.reply_error(
						this, (int) RpcErrorCode.INVALID_PARAMS);
					return true;
				}
				var info = GI.Repository.get_default().find_by_gtype(
					Gi.types.get(object_name));
				var fn = ((GI.ObjectInfo) info).find_method("new");
				if (fn == null
					|| (fn.get_flags() & GI.FunctionInfoFlags.IS_CONSTRUCTOR) == 0) {
					this.connection.reply_error(
						this, (int) RpcErrorCode.METHOD_NOT_FOUND);
					return true;
				}
				var in_args = new GI.Argument[this.values.size];
				for (var i = 0; i < this.values.size; i++) {
					switch (this.values.get(i).type()) {
						case GLib.Type.BOOLEAN:
							in_args[i].v_boolean = this.values.get(i).get_boolean();
							continue;
						case GLib.Type.INT:
							in_args[i].v_int32 = this.values.get(i).get_int();
							continue;
						case GLib.Type.STRING:
							in_args[i].v_string = this.values.get(i).get_string();
							continue;
						default:
							this.connection.reply_error(
								this, (int) RpcErrorCode.INVALID_PARAMS);
							return true;
					}
				}
				var out_args = new GI.Argument[0];
				var ret = GI.Argument();
				try {
					fn.invoke(in_args, out_args, out ret);
				} catch (GLib.Error e) {
					this.connection.reply_error(
						this, (int) RpcErrorCode.INTERNAL_ERROR);
					return true;
				}
				var created = (GLib.Object) ret.v_pointer;
				this.connection.export(created);
				var response = new Response();
				response.result.add(created);
				this.reply(response);
				return true;
			}
#endif
			GLib.critical(
				"RPC dispatch: no handler for '%s' (%s)",
				object_name,
				this.method
			);
			return false;
		}
```

```vala
			rpc.call.begin(new OLLMrpc.Request() {
				method = "Gio-Menu.new"
			}, (obj, res) => {
				response = rpc.call.end(res);
				call_loop.quit();
			});
			call_loop.run();
			this.check(command_line, response.error == null, "new returned error");
			this.check(command_line, response.result.size == 1, "new returned no object");
			this.check(command_line, rpc.proxies.size == 1, "proxy not bound");
			foreach (var id in rpc.proxies.keys) {
				this.check(command_line, id != 0, "handle is 0");
				this.check(
					command_line,
					rpc.proxies.get(id) == response.result.get(0),
					"proxy is not result"
				);
			}
			rpc.disconnect();
			listen.stop();
		}
	}
}
```

## Phase 3 — Invoke any typelib method on a handle

Goal: once Phase 2 has leased an object, the client can call **any method** that `ObjectInfo.find_method` finds on that type. Same intercept as `new`, different branch.

**Call:**

- **🔷** `⏳` Same `{alias}.{method}` as `new` (`Gio-Menu.get_n_items`).
- **🔷** `⏳` Handle names the lease. Method args stay in `values` (GIR order, **after** the instance — the instance is not on the wire as a `GLib.Value`).
- **💩** `⏳` Add `Request.object_id` (`uint64`, default `0`). Omitted on the wire when `0` (same omit rule as empty `values`). Phase 2 `new` keeps sending `0`. Phase 3 sends the lease id here.
- **🔷** Missing / zero handle on a non-`new` GI call is an error (`INVALID_PARAMS`), not a constructor.

**Server:**

- **🔷** `⏳` `Request.dispatch`: `Gi.types` has the prefix, method is **not** `new`, `object_id` is set.
- **🔷** `⏳` Lookup `request.connection.leases` for that id. Unknown id → error.
- **🔷** `⏳` `find_by_gtype` / `ObjectInfo.find_method(method)`. No such method → error (GI boundary, not a soft fallback).
- **🔷** `⏳` `FunctionInfo.invoke`: `in_args[0]` is the leased instance; remaining IN args from `Request.values`. Pack inline in `dispatch` (same value→`GI.Argument` switch as Phase 2 `new`).
- **🔷** Direction comes from the typelib (`GI.ArgInfo.get_direction`), not from the wire.

**Return:**

- **🔷** `⏳` Void → empty `Response.result` (today's empty reply).
- **🔷** `⏳` Returned GObject → `export` if needed, same handle encoding as Phase 2 (no property dump).
- **💩** `⏳` Returned scalar (int / bool / string): first smoke is `Gio-Menu.get_n_items` → `0`. Need a place to put it. Prefer a `Response.values` list mirroring `Request.values` (confirm before fencing). Do not overload `Response.msg`.
- **💩** `⏳` OUT / INOUT args: pack from GIR into `Response.values` in a later edit of the same invoke, not a wire `dir` flag.

**Smoke** (extend the Phase 2 `gi-test.vala`, after `new`):

- **🔷** `⏳` `Gio-Menu.get_n_items` with the handle from `new`.
- **🔷** `⏳` Assert the scalar is `0` (empty menu).
- **💩** A mutating method (`append` / `set_enabled`) can follow in the same test once constructor-with-args or object-valued args exist. Not required for the first Phase 3 green.

No Phase 3 fences until `Request.object_id` and scalar-return (`Response.values`) are confirmed.
