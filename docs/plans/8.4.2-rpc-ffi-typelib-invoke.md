## Purpose

- **🔷** `⏳` Phase 2 applies positional `GLib.Value`s to a real GObject method through **libffi**.
- **🔷** `⏳` Implement **typelib**: `GI.FunctionInfo.invoke`.
- **🔷** Vala `out` / `ref` / `[CCode]` are compile-time. They join this path only when a GIR/typelib exists.
- **🔷** `⏳` Additive API: `OLLMrpc.Gi.call`. `Request.dispatch`, `Request.register`, and ollmfilesd `call_*` handlers stay as they are.
- **🔷** `⏳` Smoke: in-process `Gio.SimpleAction.set_enabled` / `get_enabled` via `Gi.call` (installed `Gio-2.0` typelib). No mutter types.
- **ℹ️** gnome-shell-rpc looks up the lease, allowlists the symbol, then calls `Gi.call`. Allowlist is **not** inside `libocrpc`.

```vala
namespace OLLMrpc
{
	/**
	 * Apply positional {@link GLib.Value}s to a GObject method via typelib.
	 *
	 * Loads nothing itself — the caller must
	 * {@link GI.Repository.require} the namespace first (Gio, Meta, …).
	 * {@link call} looks up the method with
	 * {@link GI.Repository.find_by_gtype} and runs
	 * {@link GI.FunctionInfo.invoke} (libffi). Argument direction
	 * comes from the typelib, not the wire.
	 *
	 * == Example ==
	 *
	 * {{{
	 * GI.Repository.get_default().require("Gio", "2.0", 0);
	 * var on = GLib.Value(typeof(bool));
	 * on.set_boolean(true);
	 * var args = new Gee.ArrayList<GLib.Value?>();
	 * args.add(on);
	 * OLLMrpc.Gi.call(action, "set_enabled", args);
	 * }}}
	 */
	public class Gi : GLib.Object
	{
		/**
		 * Invoke ''method'' on ''target''. ''values'' are GIR arguments
		 * after the instance (IN args in this plan; OUT from GIR later).
		 *
		 * @param target live GObject (leased Meta instance, or a dummy)
		 * @param method GI method name (''set_enabled'', not ''Gio-SimpleAction.set_enabled'')
		 * @param values positional {@link GLib.Value} list
		 * @return return value, or a {@link GLib.Type.INVALID} value for void
		 * @throws GLib.Error when the typelib has no such method, or invoke fails
		 */
		public static GLib.Value call(
			GLib.Object target,
			string method,
			Gee.ArrayList<GLib.Value?> values
		) throws GLib.Error
		{
			var info = GI.Repository.get_default().find_by_gtype(target.get_type());
			var obj_info = (GI.ObjectInfo) info;
			var fn = obj_info.find_method(method);
			if (fn == null) {
				throw new GLib.IOError.FAILED("Gi.call no method %s", method);
			}
			var in_args = new GI.Argument[1 + values.size];
			in_args[0].v_pointer = (void*) target;
			for (var i = 0; i < values.size; i++) {
				switch (values.get(i).type()) {
					case GLib.Type.BOOLEAN:
						in_args[i + 1].v_boolean = values.get(i).get_boolean();
						continue;
					case GLib.Type.INT:
						in_args[i + 1].v_int32 = values.get(i).get_int();
						continue;
					case GLib.Type.STRING:
						in_args[i + 1].v_string = values.get(i).get_string();
						continue;
					default:
						throw new GLib.IOError.FAILED(
							"Gi.call payload type %s",
							values.get(i).type().name()
						);
				}
			}
			var ret = GI.Argument();
			var out_args = new GI.Argument[0];
			fn.invoke(in_args, out_args, ret);
			var result = GLib.Value(GLib.Type.INVALID);
			switch (fn.get_return_type().get_tag()) {
				case GI.TypeTag.VOID:
					return result;
				case GI.TypeTag.BOOLEAN:
					result = GLib.Value(typeof(bool));
					result.set_boolean(ret.v_boolean);
					return result;
				case GI.TypeTag.INT32:
					result = GLib.Value(typeof(int));
					result.set_int(ret.v_int32);
					return result;
				case GI.TypeTag.UTF8:
					result = GLib.Value(typeof(string));
					result.set_string(ret.v_string);
					return result;
				default:
					throw new GLib.IOError.FAILED("Gi.call return tag unsupported");
			}
		}
	}
}
```

### 5. `tests/rpc/gi-test.vala` — `Gio.SimpleAction` via typelib

**Why:** Installed `Gio-2.0.typelib` proves `FunctionInfo.invoke` without generating a GIR. `set_enabled` / `get_enabled` are ordinary instance methods.

**Where:** new file.

**Depends on:** §3.

#### Add — create `tests/rpc/gi-test.vala`

```vala
/*
 * Copyright (C) 2026 Alan Knowles <alan@roojs.com>
 *
 * Typelib invoke smoke — Gio types are not shipped in libocrpc.
 */

namespace OLLMrpcTests
{
	class TestRpcGi : RpcTestAppBase
	{
		public TestRpcGi()
		{
			base("com.roojs.ollmchat.test-rpc-gi");
		}

		protected override string get_app_name()
		{
			return "test-rpc-gi";
		}

		protected override void run_rpc_test(ApplicationCommandLine command_line) throws Error
		{
			GI.Repository.get_default().require("Gio", "2.0", 0);
			var action = new Gio.SimpleAction("p", null);
			action.set_enabled(false);
			var on = GLib.Value(typeof(bool));
			on.set_boolean(true);
			var args = new Gee.ArrayList<GLib.Value?>();
			args.add(on);
			OLLMrpc.Gi.call(action, "set_enabled", args);
			this.check(command_line, action.get_enabled(), "set_enabled via Gi.call failed");
			var got = OLLMrpc.Gi.call(
				action,
				"get_enabled",
				new Gee.ArrayList<GLib.Value?>()
			);
			this.check(command_line, got.get_boolean(), "get_enabled via Gi.call failed");
		}
	}
}

int main(string[] args)
{
	return new OLLMrpcTests.TestRpcGi().run(args);
}
```

## LLM notes

- **🚫** Change `Request.dispatch` to auto-invoke. The plugin looks up the lease and calls `Gi.call`.
- **🚫** Migrate ollmfilesd handlers to `Gi.call`.
- **🚫** Add `Gi.pack` / `Gi.require` helpers. `require` stays at the call site; packing stays inside `call`.
- **🚫** Allowlist inside `libocrpc`. gnome-shell-rpc still denies non-allowlisted Meta symbols before `Gi.call`.
- **🚫** Pass a live `Meta.Window*` in a `GLib.Value`. Lease id is an `INT` value; the plugin resolves the GObject, then passes that instance as `target`.
- **💩** `⏳` OUT / INOUT: pack from `GI.ArgInfo.get_direction()` in a later edit of the same `call` method, not from a wire flag.
- **ℹ️** `fn.invoke`’s `return_value` argument may need `out` / `ref` if valac rejects the vapi as written — match `gobject-introspection-1.0.vapi` and keep the rest of `call`.
- **ℹ️** `find_method` returning null is a GI boundary: let the cast / invoke throw rather than adding a soft fallback.
- **ℹ️** Build: `ninja -C build tests/test-rpc-gi && build/tests/test-rpc-gi` (keep `test-rpc-values` green).
